# 样本级融合的第 10 层人物特征诊断

使用 90% 原图训练的 seed1 分支，读取任务 0、3、6 各自引入时的 checkpoint，保持整个模型冻结。独立探针在本任务合法的 10% TRAIN 留出人物上学习原始 logits 的加权融合。训练人群分别为 558、995、62 人，可靠 Face 为 322、583、37 人。Validation 和 Test 沿用各阶段官方已见类人群，只评价新引入的类别。同一人物可对这些类别全为负。三个任务分别报告当前类 mAP，并对三个结果等权平均。

以精确重放同一历史人物及三路 logits 为提取前提。输入沿用历史 EMOTIC 图像、Face 清单和 CLIP ViT-B/16；特征取自 GPU0 上的 sample_holdout 正式模型。A 仅学本任务可靠及不可靠人群各自的平均读出，从可用视图均分初始化。B 计算原始与 TRAIN 标准化八维中间关联。C 读取三路第 10 个 Task Forward block 结束时的 Task CLS。D 在与 C 一致的维数、投影与可训练参数预算下，把有符号的同层交互变化加入部分 Person 和 Face 坐标。变化通过保留接收前状态、以相同任务状态重复第 10 个 block 获得，常规分类使用开启消息的正向结果。

冻结 A 后，每组通过相同训练样本上的全批 BCE 更新自己的零初始化权重，Adam 0.01、300 步，无历史固定比例锚点。D 的独立对照只交换同组人物消息，保持本人的内容。全部探针报告本人权重、组均值和同组置换，固定融合与简单等权作配对参照。

Validation 从未参与参数优化。按三个任务各自的当前类 AP 等权汇总，候选须优于 A、组均值和 100 次同组交换均值，各项至少两个任务为正。D 同时须优于 C 以及仅交换消息的对照。合格者中按 Validation 宏平均选择，均未通过则保留 A 作为诊断参照。锁定后按同一协议评估 Test。旧八阶段基线 Test 33.2019／40.2847 在后续完整训练才可直接比较。

入口为 bash scripts/emotic/run_d9_task10_probe.sh formal 0。产物目录 output/d9_task10_probe/seed1_20261118，日志目录 logs/d9_task10_probe/seed1_20261118。smoke 使用单任务、短预算，独立写入 smoke 子目录。原模型、预测及优化器状态只读。
