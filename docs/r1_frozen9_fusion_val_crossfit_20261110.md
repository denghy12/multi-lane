# Frozen9 fusion crossfit on archived Validation scores

Seed1 Frozen9 D, EMOTIC historical B5/C3 eight stages. Three deterministic SHA-256 image-group folds with salt `frozen9-val-fusion-image-group-v1`; all people from an image have the same fold at every stage. Use the existing aligned Full/Person/Face and D fixed Validation scores plus the Validation-only Face manifest, matching its SHA-256 to the prior D run. No image forward, GPU, endpoint training, or Test read.

At stage t, fit on the other two folds from the stage-t seen-class population, using only the classes introduced at t, including all-negative rows. Learn reliable three-way and unreliable two-way simplex weights independently using float64 mean BCEWithLogits, CPU SLSQP (200 iterations, ftol 1e-12), fixed R1 initialization. Compare fixed D, unrestricted simplex fitting and bounded fitting `w=0.9*w_fixed+0.1*u` with u on the same simplex. Freeze each task's coefficients for later stages within the fold. Evaluate on the held-out fold. Evaluate mixed-cohort mAP and both reliability subsets. A candidate passes if at least two folds improve both final and average mAP, with positive mean paired differences for both. Pooled OOF mAP is secondary because scores across folds use different fits.

Run `python -m scripts.emotic.run_r1_frozen9_fusion_val_crossfit`, with `--smoke` first for tasks 0/1. Inputs are the archived D Validation dumps and Val-only mask in the script. Output `output/r1_frozen9_fusion_val_crossfit/seed1_20261110`, logs under `logs/` with the same suffix. Save fold and OOF eight-stage metrics, held-out new-class BCE, weight tables, calibration support and source replays. The fixed pooled logits must replay archived D exactly. Crossfit on existing Validation scores is an exploratory check and does not replace separate TRAIN calibration and independent evaluation for a final method.
