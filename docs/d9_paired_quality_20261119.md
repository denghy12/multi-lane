# 同一人物辅助证据质量对照

## 预注册

EMOTIC 历史划分，seed1，固定受保护全 TRAIN Frozen9 Person 与 Face 接收分支。沿用各任务30轮、batch64、Adam/cosine、主学习率0.0125、Adapter 和交互学习率0.0004的原始 checkpoint。初查 task0、3、6 的引入阶段，每任务仅访问其当时合法的 TRAIN 标签；同一人物至少一个当前任务类别为正，源分支此前已按原规则训练过这些人物。Validation 和 Test 自然图像按历史已见人物人群评估当前新类别，共11类。只读三路参数和分类头。

使用确定性 TRAIN 预处理进行真实前向，逐批比对自然输入的中间信息和分类输出。在原输入外，单独将 Person 或可靠 Face 的224像素输入按面积平均降到112像素并双线性恢复，修改该视图自身像素及作为其他分支证据的同源副本。其他视图输入、Full 输出、可用性标记保持原值。修改的发送证据允许沿原有交流路径传播，故另一接收视图的输出可以改变。Face 不可用时不建立该人的 Face 训练对。所有中间信息与分类分数均来自对应版本的前向。

三组从等权开始，Face 不可用时始终只分给 Full 与 Person。A 按任务及 Face 可用性学习组平均。B 与 C 各用相同的小线性读出在20维中间特征（Task10 CLS 固定投影12维、Frozen9 跨视图关联8维）上预测可用视图的 softmax 权重。标准化仅由自然 TRAIN 得到。每名人物贡献等重，依其可用性对自然输入及1或2种变化取平均。三组都用这些相同样本最小化多标签融合 BCE，全批 Adam、学习率0.01、300步，各任务分别拟合。辅助组 A 仅由 TRAIN 学习，为 C 的配对目标提供参考权重。B/C 的初始化不使用 A 的权重。

用 A 作为共同参考，在同一版本的人物上计算去掉该视图并重新归一后的 BCE 减去全视图 BCE，即该视图对当前融合的条件收益。对一个自然/变化对计算收益差 d。C 的额外损失为 abs(d) 乘以 softplus(-sign(d) 乘以两版本该视图权重对其余视图的 log-odds 差)，在合法对上求平均，系数1。B 与 C 仅在使用此项监督上有差别。该目标测量给定已交互分类头的读出价值，其他接收分支已经获得的消息仍保留。推理只用当前人物自然图像的中间信息和可用标记，不需要再制造低清图、提供标签或运行 A 来得到 C 的权重。

一次性锁定判断条件。Validation 的三任务当期新类等权平均须满足 C 同时高于 B、A 和同任务同可靠性内错换100次的 C；每项至少有两个任务提高。另需 C 达到同底座历史固定读出三任务均值，才值得为达到正式目标投入八任务。报告无标签同组均值作为个体变动归因。锁定模型与 Validation 判定后，同批报告自然 Test，记录分类分数、身份和固定读出重放。正式八任务目标是达到同一组三路的固定融合，以及受保护全 TRAIN Test 最终/阶段平均33.2019/40.2847，报告对应 Val 两项。

服务器入口 bash scripts/emotic/run_d9_paired_quality.sh，阶段 smoke、extract、fit-val、test；数据由前序受保护 sample_full 模型、disagreement 的 task0/3 缓存和 sadness 的 task6 缓存提供，GPU0 只用于配对 TRAIN 图像前向，拟合与评估使用 CPU。输出目录 output/d9_paired_quality/seed1_20261119，日志 logs/d9_paired_quality/seed1_20261119。

## 变化来自哪里

原始 TRAIN 人数依次为5,353／9,931／627，每人均有 Person 配对；可靠 Face 配对数为3,039／5,654／441。自然版本并非总是更有用。task6 的441个人脸对中有294人原始 Face 的条件收益较高，147人低清版本较高。按收益差绝对值加权，task6 的 Face 权重调整方向与 TRAIN 监督一致的比例，B 为59.7%，C 为62.9%。task0 的 Person 对应比例为50.2%与75.1%。跨任务和视图的改善不一致，这些数仅为拟合检查。

三个任务的可靠 Face 人群中，A 给 Full 约3.3%、3.6%、3.5%。不可靠组 A 给 Full 的份额为11.5%、14.0%、13.8%。task6 的 C 给可靠组 Full 的自然 Test 平均份额为4.9%。在自然 TRAIN 人群上，task6 的固定／A／B／C 当前头 mAP 分别约94.22／97.32／97.60／97.60；在自然 Test 上分别为30.00／17.92／15.06／15.79。分支已经学习过 TRAIN 人物，融合标签又来自至少有一种新类情绪的人物。两者均可影响视图强弱估计，当前对照无法量化各自的因果贡献。

Sadness 的 Test AP 从 B 的21.4029升至 C 的23.9536；同源固定为51.5164。Suffering 从21.2129降至20.8395，同源固定为35.3844。模型可以对部分配对质量变化作出反应，目前还不足以在自然新人物上普遍选对视图。A 的平均配比已产生显著损失，使用其作为条件收益参照也是解释本次配对监督的一项限制。

本轮没有启动正式八任务。可训练最终融合的目标保留。优先核对平均视图强弱的 TRAIN 估计如何迁移，再扩大逐人拟合。执行提交174f838；首轮 smoke 发现数据加载器把可靠性标志转为浮点数，已修正为显式布尔掩码并重跑。随后12项单测及真实64人预检通过，正式4个阶段退出状态均为0。45份日志与输出已同步本地，SHA-256及两次评价封存链均核验一致。
