# 三模块叠加消融：完整 validation／test 结果与结构归因

更新：2026-10-23 14:28 CST。正式批次 `formal_seed0_20261023_01`，分支 `exp/three-module-stacking-20261022`，执行 HEAD `0fb85f1ed8c277c48ca4267d2dbe7ec1be8fcbf6`。

**本轮最值得保留的是 Image-token Adapter＋摘要 Attention，而不是三模块全开。**该双模块组的最终 validation 和 test 在八组中最高，相对本轮匹配基线分别提高 0.3880 和 0.4896 个百分点。三模块组仅在 test 阶段平均上最高，比双模块高 0.0507，但最终 validation／test 分别低 0.5817／0.2522。它说明组合收益取决于任务和训练阶段，不能将各轮单模块收益直接相加。

进一步归因显示，三模块回落在两个 split 都主要集中于 task6 的 Sadness／Sensitivity／Suffering；在三模块 checkpoint 内关闭位置项，却几乎不能恢复这些类别。这更接近**共同训练形成的任务表示差异**，而不是已经证实的“位置项在推理时直接破坏证据”。双模块的提升也没有同时伴随 Person 单路变强，不能直接汇报为三视图对应和互补问题已经解决。

## 6. 用 MULTI-LANE 的数据流解释组合为何不一定相加

MULTI-LANE 的关键区分是 Frozen Forward 提供共享图像表示，Task Forward 通过 Patch Selectors 和 Summarize 读取任务相关证据。本次保留这一边界：

```text
Full／Person／Face 各自的 Frozen Forward（相同冻结 CLIP 权重）
             │ 原 LN 后图像 tokens
             ├─第2层：Adapter 改变本层供 Selector 读取的 K/V
             │        不写回后续 Frozen Forward 的图像流
             ↓
任务 Patch Selectors 与图像 tokens 匹配
             ├─Full：人物位置项加入选择 softmax 前
             ↓
各视图的 Summarized Patches
             ├─第6层：任务 Selectors 作 Q，读取 Full 的10个摘要
             │        得到 Attention 残差，写入 Person 摘要
             ↓
原三路任务 MSA → Drop & Replace → FFN → 任务 CLS
             ↓
原归一化／固定特征融合 → 原共享分类头
             ↓
所有已见任务路径对应类别的 logits 拼接
```

这里三个模块改的是**同一条证据读取和传递链**，不是三种互不依赖的新证据。Adapter 改特征的匹配条件，位置项改 Full 摘要的选择权重，Attention 又读取这份 Full 摘要并写入 Person。因此第三个模块改变的不只是自己的输出，也改变后续模块在训练中适应的输入。

### 6.1 Adapter＋Attention 为什么值得保留，为什么还不能宣称机制成功

二者位于不同处理环节：一个改变早层 Selector 读取的图像证据，一个改变中层 Person 路径接收的 Full 信息，存在形成互补的可能。共同训练也会经融合及辅助 BCE 改变共享的本任务 Selectors、Prompt 和 head。因此整体收益可能来自读取方式、跨视图残差及共同参数的联合适应，而不一定全是推理时 Attention 传递了更准确的人物信息。

尤其需要注意：Adapter 不将改写的 patches 继续送入第6层 Frozen Forward，不能把组合解释成“Attention 读取了由 Adapter 连续优化过的骨干特征”。Drop & Replace保留任务CLS更新并恢复原任务Selectors，因此A在后层的直接影响主要沿CLS状态传播；B的Query不是此前Person图像摘要。A与B不是一条持续改写patch的串行支路，二者还会通过学习后的Selectors、Prompt和head间接适应。当前还没有针对最佳双模块 checkpoint 的开关归因，不能拿三模块的结果代替。

### 6.2 人物位置为什么没有天然补足 Attention

位置项只表达目标框与 patch 的相对几何；它不比较当前人物外观与 Full 中的某个人。Attention 的 Q 仍是任务 Patch Selectors，也不直接包含当前 Person 外观。组合可以实现“任务语义＋目标位置影响证据读取”，却还没有显式约束“所取的情境信息属于当前人物”。

同时，Attention 已经在压缩后的10个 Full 摘要上工作；位置改变后的局部信息若在 Summarize 时被混合，后面的摘要 Attention 不能保证重新区分。Full 最后仍直接参加固定融合，写入 Person 的内容也可能与 Full 重复。这些是结构的局限和候选解释，**本轮没有直接证明重复证据或压缩丢失就是唯一失败原因**。

位置只多60参数/任务，三模块比双模块总共只多480参数，不能用“参数突然太多”解释回落。训练位置 attention KL 小、无 tanh 饱和，后面的关闭归因也不支持强烈即时破坏；同样不能直接归结为“位置偏置过强”。

## 13. 下一步建议与停止条件

**第一步只检查现有最佳双模块，不再立即训练三模块。**建议用双模块 task0／2／7 checkpoint，在同一固定 validation 人群比较全开、关Adapter、关Attention、全部关闭，按Full／Person／可靠Face、task6三类及原图配对差值报告。此次现有自动归因只覆盖三模块，尚不足以回答最佳候选为什么更好。该建议没有在本轮自动执行。

若关闭Attention没有可重复损失，而跨训练模型的增益主要来自Full和共同参数，应把它定位为训练期间的联合适应现象，暂不包装为有效的推理跨视图融合。可后续评估是否能在不保留交互分支下获得同类收益，但需要匹配训练控制，不能直接把当前残差关掉当作新模型。

若双模块在多个边界确有净贡献，再单独规划小范围训练验证；优先复核task6及另一个正常任务，原图分组holdout只用于预先规定的模型选择，官方validation用于确认。若研究位置叠加，先区分早期图像适配、Full读取和Person写回的优化作用；不要直接对三模块全局增加LR、scale或层数。现有task6 holdout仅51人，不能以其单次排名决定八任务结构。

若目标仍是人物归属，应另外设计带当前人物内容并能用人物替换验证的对应约束。现在任务Selectors Q＋几何bias只提供任务和位置条件，尚未建立完整身份绑定；新机制应作为独立假设与最佳双模块比较，不应在此矩阵上继续堆叠多种改动。

现阶段保留双模块为候选、保留人物位置单独组为轻量对照，不把三模块全开作为默认；不立即扩专家、重做MoE或继续搜索温度。用户当前仅要求分析，故未启动新训练、GPU归因或额外test选择，也未提交／推送／合并代码。后续若需训练复现，应先根据validation机制证据固定候选，再安排种子复现；现有test已用于本轮观察，不能再用于调参后宣称无偏验证。
