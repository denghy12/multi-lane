# 给 Face 不可用人物的融合分数学习一个任务偏移

## 锁定的比较

EMOTIC、seed1、完整八任务，沿用90% TRAIN 原图训练的三路 Frozen9 Cross-view Attention 模型及三个任务分类分支。各任务原先训练30轮，batch64、Adam/cosine、主学习率0.0125、Adapter及交互学习率0.0004。以锁定的清晰度配对 A 为起点。A 原先在约10%按原图留出的 TRAIN 人物上用自然和降清晰度的配对输入、全批 Adam 0.01 学习300步。本轮仅在同一批 TRAIN 人物的自然三路预测上学习分数偏移。同一批人物曾用于 A 的拟合，没有参与三路分支训练；每个任务仅用引入时至少一项本任务情绪为正的人物，并使用这些人物在当前各类的全部正负标注。

对阶段内来自任务 t 的类别，取 A 融合后的原始 logit，给 Face 不可用人物加同一个 b_t，可靠人物加零。以两组人物已经锁定的 A 权重产生分类分数。每个任务仅有一个新参数，从零开始。对每个新类，比较所有来自相反 Face 状态的一正一负人物对。每对损失为 softplus(负例调整后分数 − 正例调整后分数)；先在类内按实际配对数平均，再对有合法配对的类别等权平均。数值稳定地求这一维凸目标的梯度零点。若没有足够的双向信息形成有限解，回退零并报告。每个任务的参数仅从该任务可用的 TRAIN 记录获得，学完封存，后续阶段继续使用。

Validation 和 Test 使用自然图像的既有逐人预测，按历史指标在各阶段的全体已见人物、已见类别上重排。参考包括同底座固定融合、原配对 A、配对 A 加偏移。主比较为相对配对 A 和相对固定的最终及阶段平均 mAP。以可靠性分组核对同类内部原始分数的顺序和并列关系；另记录项目正式浮点 sigmoid 口径的数值误差。训练目标考虑所有跨组正负对，AP 对正例出现在排名前端更敏感，因此二者需分别评价。Validation 完成并封存后再评估 Test。

使用 CPU，入口 scripts/emotic/run_d9_group_offset.sh，依次执行 smoke、fit、val、test。输入为 d9_paired_a_eight 的配对 TRAIN 缓存、readout/centers_lock.json，以及 sample_holdout 的原图划分和八阶段官方评价预测。结果目录 output/d9_group_offset/seed1_20261119，日志目录 logs/d9_group_offset/seed1_20261119。

## 偏移的监督与归因

八次拟合均有双向配对，独立复算的梯度根与正式实现误差小于0.000001。下表的人数仅在各自任务内计数；一个人可以跨任务出现。参与拟合的是各任务至少一个新类为正的 TRAIN 留出人物，这与完整已见人群的组成有差异。

| 任务 | 拟合人数／Face不可用人数 | 不可靠正例对可靠负例的对数 | 可靠正例对不可靠负例的对数 | TRAIN 损失，前→后 |
| --- | ---: | ---: | ---: | --- |
| task0 | 558／236 | 27183 | 28877 | 0.261539 → 0.260112 |
| task1 | 439／167 | 17357 | 17314 | 0.343720 → 0.334852 |
| task2 | 80／26 | 931 | 817 | 0.809669 → 0.809476 |
| task3 | 995／412 | 103981 | 101713 | 0.561980 → 0.559196 |
| task4 | 423／114 | 8385 | 8418 | 0.201504 → 0.196218 |
| task5 | 251／75 | 6818 | 7190 | 0.366511 → 0.365266 |
| task6 | 62／25 | 714 | 606 | 0.449260 → 0.434895 |
| task7 | 126／38 | 2159 | 2109 | 0.548114 → 0.547255 |

训练损失八项均降。相对同一组三路、同一套 A 的零偏移，Val 和 Test 的八阶段 mAP 全降。最后阶段的跨组正负排对率在 Val 从70.4213%降到70.0633%，Test 从69.3964%降到69.1875%。各阶段这一独立于 mAP 的指标也全降。组内原始 logit 的严格名次与并列关系在两 split、全部阶段和类别逐项保持。正式 FP32 sigmoid 的少量近似并列使 Test 不可靠组的阶段 mAP 最大变化0.000045点，可靠组各阶段完全重放。

task6 的62名融合训练人物中有25名 Face 不可用。它们学出的共享偏移为+0.4901，三种情绪都向上平移。最终 Sadness 的跨组排对率在 Test 从88.118%降到86.856%，总体 AP 下降3.7282点；Suffering 的总体 AP 下降1.7090点。一个常数可以改变两组相对名次，但这种基于 TRAIN 估出来的整组平移，没有在新人物上提高排序。筛样差异、每个情绪的相对偏差及小样本都是可能影响因素，当前实验没有分别隔离。

建议保留零偏移 A 作学习读出对照，按原计划优先定位可靠 Face 人群内部的三路配比。先在同一缓存上区分两种因素：分别改变 Face 份额，或改变非 Face 份额中 Full 与 Person 的相对分配，保持另一因素及 Face 不可用组不变，同时核对组内与全体排序。这样可以判断哪一个比例有更明确的改进目标。这些替换仅用于诊断。
