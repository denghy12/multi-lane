# Frozen9 reliability-conditioned logit fusion

Fit separate task-local simplex weights after the three original heads. For reliable Face, fit Full/Person/Face weights. Otherwise, fit Full/Person weights with Face weight zero. The original R1 ratio is the feasible starting point. Use raw logits and sigmoid after fusion, consistent with the source D model.

- EMOTIC historical B5/C3 split and seed1, all eight tasks. Reuse completed D endpoints: native R1 Full and the original two Frozen9 patch receivers. No optimizer step for the view paths, no changes to crops or reliability. Original endpoints trained for 30 epochs/task with batch64, Adam/cosine and original per-view BCE plus Adapter-ASL.
- GPU0 exports deterministic TRAIN logits with the archived evaluation AMP and batch64, two workers, using each task's completed compact checkpoint. Run all seen lanes to match eval arithmetic, then retain only newly introduced classes and current-task eligible TRAIN people. Save aligned IDs, labels, reliability and class indices in each export.
- CPU float64 SLSQP, 200 maximum iterations and ftol 1e-12, objective mean BCEWithLogits with no regularization. Fit the two groups separately. Fit the tied Full/Person control with three deterministic starting points. A group with no eligible rows retains its fixed weights.
- Five predeclared groups: fixed; learn reliable only; learn unreliable only; learn both independently; share the conditional Full/Person relative ratio. Keep each task's weights with the classes introduced by that task. Report all eight stages and both reliability subgroups. The selected group must improve both validation mAPs over fixed, ranked by final mAP, average mAP, and then fewer free parameters. Write selection before reading any Test scores. Test then reports all five predeclared groups as descriptive comparisons without changing the selection.
- Unit checks cover known solutions, the untouched subgroup, empty group fallback, and assignment of old weights. GPU smoke uses 64 TRAIN and 64 Validation people at task0 and task7. Real branch logits must replay archived Validation outputs. During full evaluation fixed fusion must reproduce all sixteen archived D stage outputs exactly.
- Entry `python -m scripts.emotic.run_r1_frozen9_learned_fusion`, optional `--smoke`. Inputs are the historical `../multi-lane-main/datasets/EMOTIC`, `../CODE_DDP/pretrained/clip/ViT-B-16.pt`, the existing Face manifest and D endpoints/archive referenced in the script. Outputs `output/r1_frozen9_learned_fusion/seed1_20261110`, including `train_logits`, `weights.json`, Validation/Test metrics, `selection.json`, source hashes and completion record. Logs `logs/r1_frozen9_learned_fusion/seed1_20261110`.
- Calibration uses the original experts' TRAIN data. This is supervised second-stage fitting with independent Validation/Test evaluation. It is not cross-fitted calibration. Frozen branch logits have already incorporated the original feature-level cross-view evidence.
