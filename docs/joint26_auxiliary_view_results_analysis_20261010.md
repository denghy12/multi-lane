# 两个辅助视图分别有用；下一步验证增量学习中的贡献

## 本轮结论

Full+Person、Full+Face 都已分别从头训练，三个 seed 在 validation 和 test 上均优于只输入 Full。现在可以更有依据地说：Person、Face 各自携带了有用信息，而不只是三路模型在增加计算量后整体变好。

三路在 validation 的三个 seed 中都优于两路，但 test 上相对 Full+Person 的平均增益只有 0.1197，且一个 seed 为负。当前应保留三路作为参照，不能把 Face 直接判定为无效，也不能宣称三路在所有情形下一定优于 Full+Person。

本轮全部关闭 ParaX、Image-token Adapter。它定位的是辅助视图贡献，不是新一次 ParaX 效果验证。增量适用性尚未由本轮证明。

## 完成情况与中断原因

- 六次训练均完成30epochs、7,530有效更新、零AMP跳步，loss scale全程1024；train=16,001人物，26类同时训练，一个Task Forward pathway。
- 原队列在seed2训练结束后发现GPU1空闲显存低于14GB，按保护条件停止。因此之前是“训练全部完成、最后两次test未运行”，不是模型训练失败或OOM。
- 2026-10-10显卡空闲后，直接恢复seed2两个最终checkpoint的test；未重新训练、未改变参数、未选择其他epoch。恢复首批validation logits的最大差异均为0。
- 三seed共六次test全部完成，test=5,368人物；原Full与三路参照复用既有稳定AMP模型。逐seed样本、标签、初始参数、首批训练ID和CLIP hash配对通过，明确记录来源Git版本不同。
- 已同步训练/测试分数、日志、配置和审计，102个文件远程/本地SHA-256一致；compact checkpoint保留服务器。新实验队列改为有限等待GPU，避免同类临时占用直接终止队列。

## 结果：三seed均值与标准差

全部使用固定第30轮模型；标准差为三个seed的样本标准差，mAP单位为百分点。旧的高AMP初值seed0不混入本表。

| 实际输入与修改 | Validation mAP | Test mAP |
| --- | ---: | ---: |
| 只输入Full，冻结共享CLIP | 49.1347 ± 0.5290 | 38.2098 ± 0.2808 |
| 输入Full+Person，固定融合0.80/0.20 | 49.9985 ± 0.1720 | 39.1081 ± 0.2444 |
| 输入Full+Face，可靠Face时固定融合约0.762/0.238，否则只用Full | 50.0671 ± 0.0498 | 38.7573 ± 0.1665 |
| 输入Full+Person+Face，沿用固定可靠性融合 | 50.7980 ± 0.3175 | 39.2278 ± 0.0916 |

各组共享同一CLIP参数；Selector、任务提示和分类头在启用的视图之间共享。融合位于Task Forward输出的归一化任务特征之后、共享分类头之前。两路权重由原先验删除缺失视图后归一，未在validation或test搜索权重。

| 配对比较 | Val平均变化 | Test平均变化 | Test三个seed的变化 |
| --- | ---: | ---: | --- |
| Full+Person减Full | +0.8638 | +0.8983 | +0.6171 / +1.5008 / +0.5770 |
| Full+Face减Full | +0.9324 | +0.5475 | +0.4117 / +0.7096 / +0.5212 |
| 三路减Full+Person | +0.7995 | +0.1197 | +0.3329 / -0.1095 / +0.1359 |
| 三路减Full+Face | +0.7309 | +0.4705 | +0.5382 / +0.6817 / +0.1917 |

Person在test上贡献更明显；Face单独加入也稳定为正，但在已经存在Person时，其额外收益较小。两个裁剪视图可能包含重叠信息，属于合理解释，不能仅凭上述差值证实。mAP不是可加指标，不能把两个两路增益相加与三路增益比较后就认定存在负交互。

## 单路端点与可能的优化问题

以下都是各自联合训练模型的端点，**不是分别训练的Person-only或Face-only模型**。可靠Face只在相同子集比较：validation1,460人物，test3,261人物。

| 模型中的端点 | Val两路模型 | Val三路模型 | Test两路模型 | Test三路模型 |
| --- | ---: | ---: | ---: | ---: |
| Full+Person中的Full / 三路中的Full | 48.9904 | 49.0904 | 38.1791 | 37.7704 |
| Full+Person中的Person / 三路中的Person | 48.0916 | 48.0404 | 37.4606 | 36.8392 |
| Full+Face中的Full / 三路中的Full | 49.0976 | 49.0904 | 37.7657 | 37.7704 |
| Full+Face中的Face / 三路中的Face | 38.9342 | 38.6927 | 29.7639 | 29.2887 |
| Full+Face中的可靠Face / 三路中的可靠Face | 45.2361 | 44.1628 | 35.0567 | 34.1242 |

三路模型的Person和Face端点test表现低于对应两路模型，说明增加一个视图不会自动让每一路都更强。可能涉及共享参数上的梯度权衡、视图冗余和融合权重，但本轮没有梯度冲突测量，也没有搜索最佳融合权重，不能确定唯一原因。

此外，两路与三路的辅助损失都为0.1×可用视图BCE均值，单个分支分到的辅助损失系数不同；固定融合系数也经过重归一。因此这是输入组合的完整消融，不是只改变某一路特征、保持其余所有优化项完全不变的因果干预。

在同一个两路模型中，Full+Face融合test38.7573高于其Full端点37.7657，说明Face尽管单路较弱，仍能提供互补信息。不能因为Face单路mAP低就直接去掉它。

## 不同情绪类别的描述性变化

按三个seed每类AP差值取均值：Full+Person相对Full改善23/26类，Full+Face改善19/26类。前者在Happiness/Sadness/Anger约提高2.5656/2.2292/2.0747；后者在Aversion/Happiness/Surprise约提高2.8333/2.4221/2.3613，也在Pain/Sensitivity/Sympathy约下降1.0197/0.8629/0.7812。

三路相对Full+Person改善15/26类，Fatigue/Happiness/Disconnection约提高2.0336/1.5230/0.9595，但Sympathy/Sensitivity/Annoyance约下降1.4316/1.0510/0.8356。平均收益较小包含改善与退步的抵消。这是不同训练模型的对比，不能直接理解为Face只负责某些情绪，也不据此调整类别权重。

三个seed提供了方向和波动信息，不能当作所有数据分布下的保证。test已多次用于报告，后续继续使用时也不能声称是从未查看过的测试集。

## 对ParaX困境的更新

先前联合训练三路ParaX的test平均39.6299，比三路无ParaX39.2278高0.4021；validation增益只有0.1471且未过既定开发线。这一结果仍保留，不因本次消融改变。

本轮进一步排除了“Person和Face根本没有信息，所以ParaX一定不可能有效”这种解释。更需要区分的是：如何利用辅助信息，以及新任务更新共享变换时如何保住旧任务。ParaX参数路由、最终视图融合、跨任务参数稳定是三个不同问题。

冻结CLIP原权重不等于保持所有激活不变；共享ParaX持续更新会改写旧任务输入。当前不扩大ParaX、不增加level embedding或动态融合搜索。先在实际增量协议中验证视图组合，获得可用于后续路由研究的稳定参照。

## 下一步：八任务增量、四种输入组合

配置见 [增量视图贡献实验方案](incremental_auxiliary_view_contribution_plan_20261010.md)。Full、Full+Person、Full+Face、三路各跑seed0/1/2，八任务、30epochs/task，关闭两种Adapter，固定融合、共享冻结CLIP；每个任务结束报告锁定test。

同时对固定task0样本的旧五类保存logit漂移与mAP变化。随着任务增加，常规评估样本集合会扩展，AP变化可能包含样本组成变化；固定旧样本有助于区分真实表征/输出漂移与这种评估效应。

如果三路增益在增量学习中保持，优先保留三路稳定骨干；如果Full+Person更稳定且没有可靠的Face额外收益，可优先采用两路简化模型。后续受限融合应按任务保存并冻结其参数，避免在所有旧任务上持续更新同一变换；本轮不自动启动这些后续结构。
