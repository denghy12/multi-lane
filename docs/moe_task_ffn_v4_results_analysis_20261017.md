# Task-Forward MoE v4：完整结果与下一步决策

日期：2026-10-17。mAP/AP以百分数表示，差值为百分点。主结论仅对应seed0；所有区间均为500次原图聚类配对bootstrap，未做多重比较校正，不包含训练seed不确定性。

## 1. 结论

v4修复了v3的机制缺陷：专家实际变换图片证据，MoE只写任务CLS，输出不再集中在恢复后的Selector。专家输出随图片变化且幅度充分，Router与图片的对应关系也有局部作用。但是dynamic没有超过普通共享或固定视图控制，test的8个阶段点估计全部低于B0；新增接口尚未转化为可复现的泛化收益。

当前保留B0，不晋级v4、不扩专家/层数/LR/噪声/训练seed，不合并main。固定视图组只有最终test小幅正差、阶段平均仍负且区间跨0，也不能当作已成功方法。

“可靠Face单路变好”不等于三视图互补性改善。新增同checkpoint验证显示Face-only残差并未提高融合，不能据此直接重启Face后置校准。若继续研究，下一步先定位共享梯度冲突及训练内泛化，而非立即训练v5。

## 6. 专家与Router机制确实工作

- 专家输入为本块实际图片证据，MoE残差在所有只读前向的Selector位置严格为0。
- 24个任务池/视图的实际CLS残差/输入CLS平均比范围4.52%–26.52%，中位数9.62%；不是弱到没有作用。
- 专门/共享CLS输出范数比范围0.987–4.357，不能继续把专门专家训练不足作为默认解释。
- 共享/专门输出夹角余弦0.454–0.882；三视图门控与输出并非完全相同。
- 专门输出跨图变化能量占比15.67%–59.95%，组合CLS残差9.97%–48.97%；不是仅由共同偏置主导的固定Selector重写。该比例是总能量中去均值后的跨样本能量，不是分类解释率。
- 选中两专家的门控熵0.643–0.693，接近ln2；权重多接近各0.5，动态性主要来自选择哪一对专家。所有池/视图访问过三名专门专家；task4 Full最常见配对仍占92.16%。

## 9. 下一步方案：先诊断共享优化，再决定是否继续

### 立即决策

1. 保留B0作为当前结果；v4只归档，不扩seed、不合并main。view-fixed可作为固定路由控制保留，但不是已确认的替代方案。
2. 停止当前Task-Forward MoE结构的容量/温度/噪声/LR/scale搜索。当前同时具备足够输出和内容变化，却没有优于控制的融合收益，已触发本轮预声明退出条件。
3. 不在test上搜索关闭哪些视图、Face阈值、融合权重或checkpoint。Full-only/Face-only只作validation机制定位。

### 如继续三视图共享研究，下一步限定为只读梯度归因

使用现有task0/2/7 checkpoint和固定训练样本组（例如每task四个batch64，按原图分组，保留原loss/Face mask），不更新参数；比较B0/shared/view-fixed/dynamic的：

- 每视图监督对共享Expert、Selector、Prompt、classifier的梯度范数；
- Full↔Person、Full↔Face、Person↔Face梯度余弦与负余弦占比；
- fused BCE与0.1 auxiliary view loss各自贡献，Face按可靠/不可靠样本分开；
- 共享/专门参数的冲突是否在不同batch、task重复，是否与Full的高固定权重及弱视图监督有关。

当前分支消融支持“联合适配/共享优化存在干扰”这一待验证假设，但AP变化不等于梯度冲突的直接证据，不能预先断言优化是根因。

如果稳定冲突得到证实，下一候选应只改变梯度流/监督分配：固定视图路由作为稳定控制，保护B0主路的原始梯度，测试共享参数上的按视图梯度平衡或隔离专家loss；先验证主路保真及训练内图像分组holdout上的融合净收益，再考虑新训练。它是条件方案，尚未实现/运行，也不能承诺优于B0。

如果没有稳定冲突，或即便隔离后仍没有互补净收益，应结束这个插入位置的MoE路线，回到B0。项目已有Full-anchored residual、OOF排序/蒸馏、后置feature/logit校准的失败或不足晋级记录，不能将它们换名重启。

未来模型选择应优先使用训练内按原图分组、按来源审计的holdout/OOF；只有最终与阶段平均、Full保护和融合边际收益一致，才锁定新报告。val/test已经多轮用于研发反馈，当前单seed小差值不足以支撑新机制结论。

本次否定的是当前单层、任务独立池、三视图迁移组合；并未复现论文的全层视觉/文本适配、跨任务共享专家与activate-freeze/DDAS，因此不能外推为原始MoE-Adapters方法无效。
