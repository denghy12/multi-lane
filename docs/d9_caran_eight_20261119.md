# CARAN 式人物逐类融合的八任务配对实验

## 实验问题

以同一条 seed1、90/10 的受保护 Frozen9 训练轨迹为基础，分别检验允许不同类别使用不同比例，以及让比例随当前人物变化，对多标签排序的增量价值。保留输入原图、Person、可靠 Face 的 Multi-LANE 分支、Task Selectors 与历史任务头。

| 融合参数 | 当前任务内共享 | 按当前类别独立 |
| --- | --- | --- |
| 只看任务及 Face 可用性 | A，两个可用性组各学一套视图常量 | 每个类别在两个组中各学一套常量 |
| 再看本人的三路最终 Task CLS | 单层线性读出，为每人输出一套三路比例 | 单层线性读出，为每人每类分别输出三路比例 |

## 训练与评价约定

使用原始 EMOTIC 历史划分、seed1、8任务。源 checkpoint 来自 sample_holdout，三路按原配方训练30轮，batch64，Adam/cosine，主学习率0.0125，Adapter和交互模块0.0004。数据按原图划分。约90%的TRAIN原图用于分支，约10%的TRAIN原图用于融合，每任务只使用当时合法、至少一个当前类别为正的人物。确定性预处理，采用原评估的 batch64、GPU0，在各阶段逐值核对源预测。

两个输入人物内容的读出共同使用当前任务的三个原分类头实际接收的最终 CLS。融合时使用未经 sigmoid 的分支分类分数，类别内沿可用视图做 softmax。Face 不可靠时遮蔽其特征并令其权重为零。四组参数从零初始化，等权起步。每组每任务全批 Adam、固定学习率0.01、BCE、300 次更新，无 19% 限幅。只更新融合层，旧任务读出在其引入后封存。这是冻结已有分支的读出实验；与原 CARAN 的整网训练时序有所区别。

主比较预先指定为人物逐类相对逐类常量及人物共用比例。两项对比只改变表中的一个因素。另核对 A 与历史固定比例、全 TRAIN 受保护基准。记录完整八阶段 Validation、Test 的最终和阶段平均 mAP、逐任务表现。人物对应诊断在同任务、同 Face 可用性内联合交换某个人该头所有类别的比例，保留接受者的三路分类分数，重复100次，估计本人的权重是否优于错配。对照与配置于访问本轮 Test 前固定。

人物×类别的主要判断看 Validation 的最终与阶段平均 mAP 是否同时超过逐类常量和人物共享读出，另列本人对错配的差值。Test 使用全部同样的候选与协议，不据 Test 选择超参数。还报告八阶段结果对同轨迹固定和全TRAIN固定基线 33.2019／40.2847 的差距。100次置换只量化在给定人物上交换比例的影响，单一训练 seed 的跨种子稳定性仍待复验。

## 八阶段结果

除第一行外，各行使用相同的 90% 分支输出。每项都是全体已见人物、全部已见类别的 mAP。

| 读出 | Val 最终 | Val 阶段平均 | Test 最终 | Test 阶段平均 |
| --- | ---: | ---: | ---: | ---: |
| 受保护全 TRAIN 固定比例 | 43.6272 | 51.1094 | 33.2019 | 40.2847 |
| 90% 分支固定比例 | 43.1226 | 50.6976 | 32.4573 | 39.9684 |
| 可用视图等权 | 41.4112 | 48.9681 | 31.0899 | 38.9389 |
| 任务平均 A | 43.2230 | 50.8632 | 32.3818 | 39.7271 |
| 每类学习常量 | 42.6656 | 49.6060 | 32.3902 | 39.7067 |
| 按人物变化，任务内共用 | 39.0993 | 46.8260 | 29.0327 | 36.8513 |
| 按人物、按情绪分别学习 | 37.9011 | 45.3997 | 28.4186 | 36.4565 |
| 逐人逐类的组平均权重 | 39.5929 | 47.0829 | 29.6971 | 37.9568 |

两种 split 的全部八个阶段中，人物逐类读出均低于逐类常量和人物任务共享读出。Test 最终26类中，人物逐类相对逐类常量只有3类提高，Validation 为5类。Test 最终与阶段平均分别比同模型固定融合少4.0386、3.5118点。

## 人物权重与人物能否配对

| 人物权重减同组错配，100次平均 | Val 最终 | Val 阶段平均 | Test 最终 | Test 阶段平均 |
| --- | ---: | ---: | ---: | ---: |
| 任务内共用 | -0.1258 | +0.2084 | -0.0686 | -0.0460 |
| 人物逐类 | +0.1323 | +0.2229 | +0.3624 | +0.3387 |

本人逐类权重比打乱更好，说明在这组固定样本上保留了人物对应线索。它仍低于按组固定采用自己的平均比例。估计平均比例时按任务、类别和 Face 可用性使用 Validation 的预测权重，不使用标签，Test 使用同一封存均值。错配保留了同组比例的波动，均值去掉了这种波动，两项对照检验的是不同问题。

## task6 排序与训练误差

以下 BCE 在 task6 引入当时只取其三个当前类。TRAIN 是融合留出人物（62人），Validation/Test 是阶段评价人物（2397/5367人）。

| 读出 | TRAIN BCE | Validation BCE | Test BCE |
| --- | ---: | ---: | ---: |
| 任务平均 A | 0.5290 | 0.6963 | 0.6967 |
| 每类常量 | 0.5247 | 0.6968 | 0.6958 |
| 人物任务共享 | 0.4116 | 0.8314 | 0.8405 |
| 人物逐类 | 0.3228 | 0.8692 | 0.8748 |

该任务的逐类人物读出有13,842个名义参数，输入为三路各512维的原生分类头前特征。62名TRAIN人物中仅37名有可靠Face。在Test可靠Face人群中，对Sadness分配给Face的平均份额为77.86%，83.93%的人将Face列在三路之首。到最终阶段，Sadness、Suffering 的AP相对逐类常量分别下降33.2166、12.2211点，Validation 相应下降34.5737、19.8040点。在Test中仅取与TRAIN入选条件相同的391名当前情绪阳性人物，A／逐人逐类BCE也由0.6660升至0.8086。结果与高自由度门控过拟合一致；单个seed的这组对照尚不能把损失单独归因于参数量、某条分支或某个超参数。

运行入口为 `bash scripts/emotic/run_d9_caran_eight.sh`。提取代码19819e4、读出代码13a2bc4、完成运行版本92b3483。GPU0从源checkpoint重新前向，TRAIN和两个评价split共24份正式特征存档逐值重放分类分数、人物与标签，A重放上一轮。16项回归与真实数据预检通过。首次提取结束后的日志汇总遇到多文件 tail 选项错误，修复后对所有已产出特征重新做哈希校验并继续，固定数据和权重未受影响。5个阶段退出码均为0。原生特征、逐人输出、报告和日志共101个文件已同步至本地并通过逐文件 SHA-256 核验。
