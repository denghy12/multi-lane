# 从第 10 层任务内容学习三路可靠性

## 预定协议

使用 EMOTIC 的官方历史划分、seed1，复用受保护 Frozen9 Person＋Face 的同一 90/10 轨迹。按原图永久分工，Full、Person、Face 以约 90% TRAIN 训练 30 轮（batch64、Adam/cosine、主 LR 0.0125、Adapter/交互 LR 0.0004）。每任务只用该任务可用、至少一个新类为正的 10% TRAIN 留出人物训练融合。Task0、3、6 分别有 558、995、62 人。拟合数据和任务间独立，旧头保持封存。Validation 与 Test 使用各阶段全体已见类评价人群，含当前类全阴性人物。

1. 读取历史 CARAN 人物逐类权重与同一人物三路 logits。只评价 task0、3、6 在各自引入阶段的新类。按任务、类别、Face 可用性比较低权重与高权重人物。单路正确性为分支分给真实二元标签的概率；补充收益为历史固定读出在 Full 向待测分支转移 5 个百分点前的 BCE 减改变后的 BCE。对不可靠 Face 只分析 Person，保留正/负例分别统计。该动作使用标签分析已保存预测，不用于学习或推理分配比例。以 Validation 解释结果并同时报告 Test。两项指标是观察关联，不能单独证明互补性或重复信息的因果作用。
2. 若可信度监督有进一步诊断价值，沿用原第 10 个 Task Forward block 结束时三个 Task CLS 的冻结缓存、原 3×4 维投影及只在 TRAIN 计算的标准化，比较 A、B、C。A 学各可用性组的任务常量；B、C 同一低维线性门控，在组截距上叠加人物输入，所有可学权重从零开始。各路评分经过有效视图 softmax 后加权原分类 logits。A 和 B 使用相同融合 BCE；C 在 B 上以系数 1 加入有效视图的可靠性均方误差。可靠性预测采用 softmax 前每路分数的 sigmoid，目标为各当前类别真实二元标签概率的算术平均。分支、特征与可靠性目标无梯度，三组共用相同预测。这是 Multimodal Dynamics 显式置信度监督的多标签改写。该论文的原始实现用可信度加权特征，再拼接分类。
3. 三组各自全批 Adam，学习率 0.01、300 次更新，确定性 CPU 单线程。按三个任务当期新类 mAP 等权平均，并报告每个任务；固定比例作为配对对照。Validation 预定判据为 C 相对 B、A、自身同可用性组均值、100 次同组换人平均均为正，且各比较至少两个任务为正。组均值由 Validation 的预测权重获得，仅作归因，封存给 Test。Test 按相同锁定方案报告。通过上述 Validation 门槛才推进从头完整八任务训练，再分别对照同组三路固定读出及全 TRAIN 受保护基准 Val 43.6272/51.1094、Test 33.2019/40.2847。

执行入口为 `bash scripts/emotic/run_d9_tcp.sh <phase>`。只读输入为既有 d9_caran_eight 与 d9_task10_probe 输出。无需加载 ViT 或运行 GPU 前向。日志按阶段写入 `logs/d9_tcp/seed1_20261119`，逐组统计、拟合参数和验证锁写入 `output/d9_tcp/seed1_20261119`。诊断引用末层 CLS 门控已保存的权重，新的控制只读第 10 层中间特征，两者检验的问题不同。

## 结果

诊断、5项回归、task6 真数据预检、三任务正式拟合、Validation 锁定及 Test 复评均完成。阶段一诊断版本 a07843d，正式读出版本 7dc659f。九份源特征档案通过 SHA-256、人数、任务与来源核验。A 与固定对照在六个任务/评价集组合上重放先前结果。32 个输出与日志文件已同步本地，逐文件散列一致。

C 对 B 的平均 mAP 差为 Val +0.8241、Test +0.9823，两者均为三个任务中两个提高。C 对任务平均 A 为 −4.9808/−2.9898，对自己的组平均为 −3.0969/−1.7849，对 100 次换人为 −0.5113/+0.0235。Validation 只通过相对 B 的一项，正式八任务训练保持未启动。

可靠性目标预测均方误差（各任务等权）由 B 的 Val/Test 0.2162/0.2147 降至 C 的 0.0456/0.0464。B 的评分仅受融合 BCE 训练，softmax 对所有视图分数的共同平移不敏感，因此该 MSE 差主要表明 C 被训练成了更接近目标绝对尺度的输出，人物排序能力需另验。Task6 中 C 的 Face 评分与实际真实标签概率在人群内的 Pearson 相关为 Val +0.021、Test −0.025。共有62名 TRAIN 留出人物（37 名可靠 Face），三个情绪共用同一套人物比例。对比 A，Sadness 的当前类 AP 在 Test 由46.2387降为23.9803，在 Validation 由48.3421降为20.7164。Task6 的个体波动相对同组均值在 Val/Test 分别损失9.1353/5.3911点。可以推断此设置对平均可信度的拟合改善，但对未见人物调整比例的收益仍不稳定。负例贡献、监督对类别取平均及留出规模均可能影响结果，目前未拆分其因果贡献。
