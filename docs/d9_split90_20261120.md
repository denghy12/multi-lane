# 同一 90% 原图预算下的三视图分支对照

数据为 EMOTIC 官方 TRAIN／Val／Test。沿用 seed1、冻结 CLIP ViT-B/16、Frozen9 Person 和 Face 接收、分支原监督及梯度保护。原图总数12,915；每种划分11,623张用于三路训练、1,292张用于留出。同图人物和视图始终同侧，一旦分配原图即封存。正式组固定每任务30轮、batch和microbatch均为64、BF16、2个加载进程、Adam、主学习率0.0125、Adapter及交互0.0004、原cosine日程。每轮有效分支更新数分别为84、69、14、156、68、40、10、24，合计13,950。预训练权重、输入图像和人脸记录按项目相对路径 `../CODE_DDP/pretrained/clip/ViT-B-16.pt`、`../multi-lane-main/datasets/EMOTIC`、`../emotic_benchmark_runs/` 复用。逐任务核对曝光次数、末批、学习率和原图归属。

| 组别 | 原图分配方法 | 比较用途 |
|---|---|---|
| 原始随机 | 历史等步数模型的原始哈希分图 | 同预算参照，复用已完成的八阶段预测 |
| 第二份随机 hash2 | 只更换给图片排序的固定哈希，模型与组批seed仍为1 | 测量换一份普通样本名单的影响 |
| 元数据分层 meta | 按图中人数和可靠Face情况分层，层内用同一新哈希分图 | 检查训练两侧人物结构接近原分布是否有益 |
| 当前任务分层 online | 对首次进入当前任务的图，平衡当前类和其中可靠Face正例数，之前分好的图保留原角色 | 检查在增量协议下改善少数情绪覆盖的作用 |

CPU审计只使用TRAIN。保留历史原生辅助门控以重放训练条件；各分支接受各自原监督。首轮只用Full、Person、可靠Face的单路表现和固定比重的全人群融合（可靠0.64／0.16／0.20，其余0.80／0.20／0）判断视觉分支效果。未引入新的配对A拟合。冻结的ViT权重始终相同，所谓分支提升指任务可训练部分在未参与训练的人物上的效果。

首要报告固定融合的最终／阶段平均，再分开报告各视图。若分层组两项Val融合均优于原随机及第二份随机，且有同向单路表现，作为候选；取舍按指标分别报告。归因于划分机制还需独立配对复验。全部策略的Validation完成并封存后统一报告Test。全TRAIN固定Test 33.2019／40.2847作绝对参照，原等步数90%固定为32.7557／39.9983。

入口 `bash scripts/emotic/run_d9_split90.sh preflight 0` → `smoke 0` → `formal 0`。三组在GPU0并行，各自独立模型和恢复点。实验结果在 `output/d9_split90/seed1_20261120`，日志在 `logs/d9_split90/seed1_20261120`。数据加载、训练入口及历史评估代码复用；出现显存不足时从已有的完整epoch恢复、串行补跑。

## 正式训练启动与原图核验

三组在 GPU0 自 2026-11-20 16:13 起运行，代码版本 `60d38b3`。12 项回归检查、三组真实图片的两任务 smoke（包括 Val／Test）通过。正式 task0 第一轮每组均有 84 个有效更新、零跳步。CPU 独立重放三组全部 720 个训练轮次，三组每个 batch 内的人物均不重复，每轮覆盖全部合法分支训练人物。最终训练有效更新数以各组正式历史为准。

| 划分 | task6 分支人数 | task6 留出人数 | 留出可靠 Face 的 Sadness／Sensitivity／Suffering 正例 |
|---|---:|---:|---|
| 原随机 |565|62|24／14／8|
| 第二份随机 |571|56|17／18／16|
| 按人数和人脸分层 |572|55|17／19／14|
| 按当前情绪分层 |544|83|22／22／14|

元数据分层使用与第二份随机相同的排序，两组在 1,292 张留出原图上有 1,269 张相同，实际只替换 23 张。在线类别分层把 task0 的 770／5,353 人和 task6 的 83／627 人划给留出。虽然四种划分的原图数相同，多人图和多标签人物的分配会改变分支实际见到的人数。在线组在 26 类中留出可靠 Face 正例最少的类别有 7 人，原随机为 5 人。上述数字来自 TRAIN，可直接查看 `output/d9_split90/seed1_20261120/audit/` 各组的原图名册和逐类人数。

上一轮只改变分支步数，固定融合 Test 从 32.4573／39.9684 提高到 32.7557／39.9983；再固定等步数模型，使用自然图学习比例达到 33.0091／40.1539，加入降清晰度配对达到 33.0601／40.1808。测试最终和阶段平均对分支训练与融合的响应不同。本轮统一用固定比例比较选图。
