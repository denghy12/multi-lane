# 全量学习三 seed 与 test 结果：三视图有效，ParaX 的收益需要谨慎解释

## 给导师的结论

本轮把 EMOTIC 的 26 个情绪类别同时训练，不再按八个增量任务依次学习。三次随机初始化都表明：增加 Person 和 Face 后，整体优于只输入 Full。共享 ParaX 在全量学习中没有出现之前增量实验的大幅退化，test 上也有小幅正收益。因此，不能再概括为“ParaX 完全不适用”。

但 ParaX 的 validation 收益较小且方向不完全一致，没有达到事先规定的开发晋级门槛。它在 Full 单路中也有相近的 test 增益，Face 单路的平均 test 表现反而下降。当前证据支持“全量学习下存在小幅适配收益”，尚不支持“已经通过动态参数路由解决了三个 level 的专门化与增量稳定性”。

下一步保留共享冻结编码器，补充分别重新训练的 Full+Person、Full+Face，对两个辅助视图的独立作用做清楚的消融。暂停扩大内部 ParaX、增加专家数、增加插入层或重新搜索动态融合。

## 这次实际比较的架构

- 四组均使用同一冻结 OpenAI CLIP ViT-B/16，26 类同时训练、一个 Task Forward pathway。Selector、任务提示和分类头在启用的视图之间共享。
- **四组 Image-token Adapter 均关闭**。本表不是此前 bottleneck 32 与 97 的比较，也不是 Image-token Adapter 与 ParaX 同时运行的实验。
- 使用 ParaX 时，它位于 **Frozen Forward 第 11 个 Transformer block 完整输出之后、第 12 个 block 之前**，代码索引为 10；不位于 Task Forward 内部。只变换 patch tokens，CLS token 旁路。
- ParaX 使用共享的三组低秩参数矩阵专家，rank=32。路由器根据输入生成参数组合权重，三视图复用同一参数池；这三个专家不分别绑定 Full、Person、Face。router hidden=16、官方随机初始化、可学习 output scale 初值 0.1；整个联合训练期间都更新。
- 最终融合发生在 Task Forward 输出的、归一化后的各视图任务特征上，再使用共享分类头。可靠 Face 时权重为 Full/Person/Face=0.64/0.16/0.20，否则为 0.80/0.20/0。**ParaX 的参数路由不会自动改变最终视图融合权重。**

## 主要结果：稳定 AMP 三 seed

下表为最终第 30 轮，均值 ± seed 间样本标准差；mAP 单位为百分点。validation 为 2,397 人物样本，test 为 5,368 人物样本。两种数据划分的绝对 mAP 不宜直接当作遗忘量。

| 模型修改 | Validation mAP | Test mAP |
| --- | ---: | ---: |
| 只输入 Full，不加入 ParaX | 49.1347 ± 0.5290 | 38.2098 ± 0.2808 |
| 输入 Full、Person、Face，不加入 ParaX | 50.7980 ± 0.3175 | 39.2278 ± 0.0916 |
| 只输入 Full，在 Frozen Forward 第 11 个 block 后加入 ParaX | 49.4778 ± 0.2453 | 38.6025 ± 0.1871 |
| 输入三路，在 Frozen Forward 第 11 个 block 后加入三路共享 ParaX | 50.9451 ± 0.1396 | 39.6299 ± 0.1402 |

配对差值逐 seed 计算后再取均值，不使用两组标准差直接相减。

| 比较 | Validation 差值（均值 ± 标准差） | Test 差值（均值 ± 标准差） |
| --- | ---: | ---: |
| 三视图减 Full，两者均无 ParaX | +1.6633 ± 0.8304 | +1.0180 ± 0.3443 |
| Full 加 ParaX 减 Full 不加 ParaX | +0.3432 ± 0.7360 | +0.3927 ± 0.4405 |
| 三视图加 ParaX 减三视图不加 ParaX | +0.1471 ± 0.2938 | +0.4021 ± 0.1324 |
| ParaX 在三视图的增益减在 Full 的增益 | -0.1960 ± 1.0226 | +0.0093（配对均值） |

最后一行表示，test 上 ParaX 对三视图的提升与对 Full 单路的提升几乎相同。它不能单独证明三路路由没有作用，但说明当前缺少“ParaX 特别解决跨 level 问题”的强证据。三个 seed 也不足以作普遍性保证。

| Seed | Full 无 ParaX：Val / Test | 三路无 ParaX：Val / Test | Full 加 ParaX：Val / Test | 三路加 ParaX：Val / Test |
| --- | ---: | ---: | ---: | ---: |
| 0 | 49.3023 / 38.3315 | 50.5669 / 39.2814 | 49.2460 / 38.4113 | 50.7906 / 39.7908 |
| 1 | 48.5422 / 37.8887 | 51.1600 / 39.2800 | 49.7347 / 38.7851 | 50.9826 / 39.5341 |

三路 ParaX 的 validation 差值依次为 +0.2237、-0.1774、+0.3951；test 差值依次为 +0.5094、+0.2542、+0.4426。不能用 test 的较好结果反过来改写原先的 validation 晋级门槛：均值至少 +0.3、至少两 seed 为正、没有 seed 低于 -0.3。本轮均值 +0.1471，未通过；这是开发投入门槛，不是显著性检验。

## ParaX 改善了哪一路

以下是三路联合训练模型中分别取出的单路端点，**不是分别训练 Full/Person/Face 的模型**。可靠 Face 指标只在同一可靠子集比较：validation 1,460 人，test 3,261 人。

| 输出端点 | Val：无 ParaX | Val：加 ParaX | Val 变化 | Test：无 ParaX | Test：加 ParaX | Test 变化 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Full | 49.0904 | 48.8503 | -0.2401 | 37.7704 | 37.8481 | +0.0777 |
| Person | 48.0404 | 47.5498 | -0.4906 | 36.8392 | 36.9649 | +0.1257 |
| Face，全部人物 | 38.6927 | 38.3567 | -0.3360 | 29.2887 | 28.8334 | -0.4553 |
| Face，仅可靠子集 | 44.1628 | 44.3877 | +0.2249 | 34.1242 | 33.9404 | -0.1838 |
| 固定三路融合 | 50.7980 | 50.9451 | +0.1471 | 39.2278 | 39.6299 | +0.4021 |

融合 test 比各自 Full 端点高约 1.4574 / 1.7817 点，说明“不同路由的特征完全融合不起来”与本轮数据不符。单路 mAP 的升降不能直接相加预测融合 mAP：互补错误和排序会共同影响结果。Face 单路弱也不等于 Face 对融合无用。

目前三视图与 Full 的对照，只说明 Person、Face **联合加入后**有效。以前从三路已训练模型中移除一路的推理诊断，不能替代 Full+Person、Full+Face 从头训练；这正是下一步需要补齐的证据。

## 数值修复和路由诊断

- 稳定 AMP 的 12 次训练全部 30 epochs、7,530 次有效更新、零跳步，loss scale 全程为 1024。
- ParaX 的三 seed 梯度有限性记录均为 1。去除 AMP 放大后的三路模型末轮总梯度范数约 0.0629、0.0562、0.0607，不能再用旧的放大梯度日志判断崩塌。
- 三 seed 末轮 output scale 约 0.1810、0.1964、0.2532；Full/Person/Face 的 residual/token norm ratio 约为 0.149/0.146/0.107、0.161/0.158/0.105、0.276/0.293/0.223。
- 三视图 gate L1 差异约 0.1494、0.2101、0.3169，gate 熵约 0.855–1.027（3 专家最大熵约 1.099）。专家有不同使用偏好，没有证据说明全部硬塌缩为单一专家。不同 seed 的专家编号可置换，不能把 expert0 固定解释为某种 level。
- 原始 CLIP 参数 hash 前后保持一致。16 个最终 checkpoint 的首批 validation logits 恢复误差均为 0，test 推理前后方法参数、CLIP 参数和训练产物均未改变。
- 已同步输出/日志，236 个文件的远程与本地 SHA-256 一致（68 个 test 文件、168 个稳定 AMP 训练/控制/日志文件）；训练 compact checkpoint 保留服务器，未复制其大文件。

残差比例只是一次前向中特征被改动的相对幅度，不是旧任务 feature drift。联合训练没有后续任务，因此本轮不能测量 forgetting，也不应把 average-task mAP 写成全量学习指标。

## 与此前增量实验如何对应

此前持续更新共享 ParaX 参数矩阵专家，会在新任务训练后改变旧任务经过的变换；冻结共享中心能明显减轻遗忘。这支持“跨任务共享参数更新是退化来源之一”。本轮取消顺序增量后没有大幅崩塌，进一步支持这个方向。

但全量训练用一个 Task Forward pathway，增量训练用八个；数据暴露、类别监督和训练预算也不同，因此不能把两者绝对 mAP 的差异全归因于增量任务。也不能推出 ParaX 在 task0 必然有收益：本轮同时训练全部 26 类，与增量 task0 的五类不是同一个设置。

更准确的当前判断：**三视图信息值得保留；ParaX 全量适配有小幅 test 收益；增量稳定性仍未解决，视图专门化也未被证明。** 冻结的是 CLIP 原权重，而 ParaX 会改变其激活；“破坏 CLIP 权重”不是准确表述。

## 下一步已确定的实验

详细配置见 [两种辅助视图独立贡献实验](joint26_auxiliary_view_contribution_plan_20261009.md)。只新增 Full+Person、Full+Face 两种训练，seed0/1/2；沿用已完成的稳定 AMP Full 和三路模型作配对参照，避免重跑。各组仍共享同一冻结 CLIP、Selector、Prompt 和分类头，两个 Adapter 均关闭，固定权重由原先验删除缺失视图后归一，不搜索新权重。

本轮用于定位问题：哪一路能独立产生收益，两路同时加入是否互补。它不直接解决增量共享中心漂移，也不宣称固定权重是瓶颈。只有辅助视图的贡献明确后，再决定是否值得引入受限、按任务冻结的融合模块；不会仅凭当前 test 收益重新放大内部 ParaX。
