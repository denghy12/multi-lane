## 3. 从MULTI-LANE的数据流理解目前观察

MULTI-LANE的Patch Selectors在各层读取Frozen Forward的图像tokens，得到Summarized Patches，再由任务路径的Prefix-Tuned MSA与Drop & Replace形成任务CLS；各任务路径保持独立。[MULTI-LANE §3.3](https://arxiv.org/html/2405.15633v1#S3.SS3)

本实验保留上述过程，把Full的读取接口改为：

```text
Full原图 → Frozen Forward各层原tokens
                           ↓
任务Selector的语义分数 + 目标框与patch的相对位置分数
                           ↓ softmax
                 10个Full Summarized Patches
                           ↓
              原Full Task Forward → Full任务CLS

Person原Task Forward → Person任务CLS ─┐
Face原Task Forward   → Face任务CLS   ─┼→ 原固定特征融合 → 原分类头
Full任务CLS                        ─┘
```

### 3.1 新模块有学习，但改变读取还不等于正确绑定人物

目标组task0/1/2空间参数范数分别0.2144/0.1656/0.0831，末次梯度范数0.000442/0.000374/0.001906，均有限且非零。每个任务12层均记录了真实训练观测，饱和比例为0。因此“参数未接入优化器”“梯度为零”“tanh已经饱和”均不是当前记录支持的解释。

训练期间跨12层平均的绝对偏置为0.00975/0.00787/0.00451；施加偏置前后读取分布的平均KL为4.13e−5/3.10e−5/5.73e−6。统计累计整个任务训练过程，不是最终validation的开关消融，也不是两组独立模型attention之差。它支持的解释是：首版空间项目前主要作温和读取修正，尚无证据表明形成了强人物依赖。经过任务MSA和共同训练，小读取变化仍可能产生不同的最终预测，不能据KL小直接判定分支无效。

训练Frozen CLS的平均读取质量约0.10%，也没有显示大部分读取被CLS占据。不能在没有进一步证据时把失败归因于全局CLS捷径。

### 3.2 为什么普通空间偏好也可能提升

只用固定整图参考框的控制组在task0就比原方法高1.1319。它没有实际目标位置，仍可学习居中、上下或patch与Frozen CLS的相对偏好；三组共同训练也可走向不同参数解。这说明“多加一个空间模块后涨点”无法单独证明人物对应正确。目标组需要同时证明相对整图控制的优势及本人框相对交换框的优势。

task1/2目标组开始高于整图控制，是值得观察的方向；现有区间和跨阶段结果仍不支持稳定结论。不能将task0的普通空间收益解释为目标人物关系收益。

### 3.3 位置锚点仍有表达和监督边界

六维几何特征告诉模型某个patch在人物的哪里，无法单独确定其中对象与人物的实际关系，或者情绪线索属于哪一人。Frozen ViT深层patch还包含全图混合信息；读取目标附近的位置不等于取到了纯净的人物证据。

空间权重在12层共享，同一相对几何规则需要同时服务浅层外观与深层语义，表达受限。这是为首版限制参数和过拟合所作的选择，现有结果还不能判定其就是瓶颈。

仅融合BCE与原视图辅助BCE没有直接要求本人框优于同图另一人的框。分类可通过Person/Face已有信息与共用场景完成，模型因而可能只学到一般空间偏好。是否真的忽略人物关系，需要尚未生成的本人框/交换框结果验证；不能提前把“缺少绑定损失”确立为唯一失败原因，更不能立即添加损失救结果。

### 3.4 这是人物条件的Full证据提取，尚未增加三视图内容交互

空间模块读取Full tokens及人物框，不同时读取Person/Face的外观或可靠性以决定内容取舍。三路任务CLS仍按原固定比例融合。因此即使最终mAP提高，首要可成立的解释是“Full为指定人物提取了更好的证据”；只有分支与干预结果进一步支持，才可讨论三路互补性改善。

三视图仍共享Selector、Prompt及分类头。训练中改变Full的读取梯度，也可能间接改变Person/Face的参数解；同一checkpoint运行时关空间项则应保持Person/Face端点完全一致。这两种比较回答不同问题。正式分支诊断尚未完成，当前不能报告Person/Face已获保护或受损。

### 3.5 阶段mAP下降不构成新的遗忘证据

已读9份compact，task0→1→2旧Selector、Prompt、已见分类头行及旧空间参数逐值不变，权重有限，文件SHA前后相同。对应同一批2285人，目标组task0旧5类到task2的mAP差仅−0.00096个百分点；现有跨阶段AMP预测并非逐值完全相同，最大logit差0.01758。原方法也存在类似量级跨阶段差异，其数值来源本次未独立重放定位。

task2新增3类的阶段validation mAP，原方法10.0999、目标组10.8532，均明显低于此前类别。新类别难度与人群变化足以使累计mAP下降；不要从58降到44便判断空间模块造成严重遗忘。后续固定完整人群的正式评估与完整旧依赖审计将提供更一致的比较。

1. 原样完成已启动三组8任务；不根据中间validation更换学习率、放大bias、追加绑定损失或停掉控制组，不重新训练当前三组。

3. 在target task0/2/7的完整validation，检查正常−关闭的净贡献及本人框−交换框的可交换者差异。Person/Face应逐值一致；同时分析多人、可靠Face及Full与融合收益，不能只看全人群平均。
4. 若完整结果支持目标组超过两控制、运行时空间项有正贡献、本人框优于交换框，再把它作为值得重复seed的候选。若只超过原方法、与整图控制和交换框无法区分，应按一般空间偏好/共同训练解释，不能汇报为人物绑定成功。
5. 若本人框确实有作用却没有融合净收益，应进一步判断Full的新增信息是否重复已有Person/Face。该情况仍不足以直接支持增加MoE、bias幅度或更多层。

当前结论：**目标位置组在前三阶段出现小幅正向validation点估计，但对照、不确定性与留出集尚未共同支持有效的人物对应机制；完整实验仍在运行，暂不能判断最终成功或失败。**
