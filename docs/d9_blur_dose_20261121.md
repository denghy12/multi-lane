# 双模糊 A 的强度与自然图训练份额

## 执行前协议

EMOTIC seed1，原随机 90% 分支、按全 TRAIN 预算补足 13,950 次有效更新、Frozen9 Cross-view Attention，独立 10% TRAIN 留出图学习比例。原人群、各任务、标签、三路 checkpoint 和各版推理均使用当前 A 的记录。八个任务的人物数为 558、439、80、995、423、251、62、126。新变体在可靠脸人群中减轻辅助信息失真或减少其训练占比。无可靠 Face 时使用原 A 的自然与身体 112 模糊训练结果。

四格为 paired_112（原尺度 112、三版等权）、gentle_168（168、三版等权）、clean_112（112、自然0.5／身体0.25／脸0.25）、clean_168（168、自然0.5／身体0.25／脸0.25）。112 是 224 的一半，168 是四分之三，回到 224 的固定输入。降采样 area、回采样 bilinear、align_corners=False，同时改变该视图自身输入与发给其他辅助视图的副本，Full 输出核对。清晰版、单独模糊身体版、单独模糊脸版各自独立前向。全部输入权重每人合计1。这里的份额是损失上各版本的权重；最终 F／P／Face 比例仍以可用视图等权初始化，Adam 0.01，恒定学习率，300次全批更新，原 BCE。默认分支冻结，仅训练每任务每可靠性组的常量。

可靠性不同的两组各有独立比例，所有候选无可靠脸的推理逐值重放 A。选优依据为自然全体 Val 最终与八阶段平均均不低于原 A，且至少一项更高，浮点容差 1e-10。多个通过的候选按 Val 最终、平均、先单因素后双因素排序。锁定权重与 Val 决策后，同批评所有 Test。强度及份额是执行前声明的单次对照，不按 Test 选择或追加档位。
