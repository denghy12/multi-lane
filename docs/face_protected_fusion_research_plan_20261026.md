# 保留已有强分路，再组合三视图：研究依据与下一阶段方案

2026-10-26。用户目标是同时提高三视图Test最终mAP与八阶段平均mAP。本次只做现有保存预测的CPU分析及文献研究，没有新训练、模型前向或checkpoint修改。当前seed1强Person候选为32.8864/39.8687，历史三视图B0为32.6800/39.5292。

## 1. 现有证据支持什么，不支持什么

旧Person+Face共训版的可靠Face单路确实较强，Face Attention ON相对OFF也有条件收益；但共训后的其他变化抵消了净收益。这说明Face信息值得继续检查，不等于任何新增Face模块都有效。

独立三个Selector库从头共训退步，且原共训头控制也退步。它去除了共同查询约束，又没有保护完整Full/Person功能，不能回答“已经学好的强Face能否无损接入强底座”。

冻结强Person只训练从零初始化Face Attention保护了底座，却没有保留旧Face模型已经学好的Adapter/Selector/Prompt/Attention整体适配，因此也没有直接回答这个问题。

新的检验应是：**先保留完整的强分路函数，检查它们能否共同改善融合；再研究如何以更低成本训练出这种组合。**

MULTI-LANE的原始做法以共享Frozen Forward和独立Task Forward隔离不同任务，Patch Selectors形成任务相关Summarized Patches，任务路径在学完后冻结。本方案借鉴其保存完整任务路径的思想，把同一任务中已经学到的不同视图路径作为可保留的功能单位；这不是原论文已经验证过的跨视图方法。[MULTI-LANE §3.3](https://arxiv.org/html/2405.15633v1#S3.SS3)

## 2. 本次已做的只读检验

输入是两个已完成模型、同阶段、同B0头下的分路logits：

- A：原Person-only共训表征+B0头。
- B：原Person+可靠Face Attention共训表征+B0头。

各阶段仍使用旧`samples_intersect_seen_classes`人群，sample IDs/标签/类别顺序/可靠Face mask逐值对齐。可靠Face权重仍0.64/0.16/0.20，不可靠仍0.80/0.20/0，不搜索新的三视图总权重。

以只换Face为例：

`z_new = z_A_fused + λ × w_face × (z_B_face − z_A_face)`。

主比较在计算前指定λ=1；同时完整报告λ={0,.25,.5,.75,1}插值，不仅展示Test最优点。不可靠Face人物直接保留A原始概率，避免不同sigmoid实现的1 ULP舍入引入假变化。

这属于保存logits的离线组合诊断。原模型先融合特征再在AMP下计算共同线性头，浮点舍入使“全部分路换B”不能与B逐值重放；因此这些数值不能冒充完整模型已复现的结果。源48个NPZ SHA未变。

### 2.3 这项检验怎样改变判断

第一，保留完整共适应后的Face函数，与从零训练一个Face Attention不是同一件事。前者已有正的融合信号，支持“强Face可以被利用”的研究动机。

第二，Person替换的信号更强。因此最终目标既然是两个融合mAP，就不应只围绕Face单路AP选择方向。Face共训也改变了Person路径，这部分可能具有更有用的互补性。

第三，Full替换控制也提高融合，尽管B的Full单路AP比A低。这直接提醒：**Full单路变差不能被当作融合变差的唯一因果解释。** 分路错误的相关性、分数标度及跨人群排序也重要。此前全OFF的ASP差值分解仍成立，但它不能进一步唯一归因于某一条分路。

第四，固定组合只是可实现性信号，不是标签条件oracle或已训练成功的方法。500次原图配对、八阶段耦合bootstrap仅估计评估样本不确定性，不估计训练seed方差，不校正Test探索。Faceλ=1的Test最终CI约[-.0676,.1918]、平均[-.0809,.2360]，均跨0；当前不能称稳定提升。

补充同一次配对抽样：只换Person的Test最终CI[.0446,.2994]、平均[.0369,.3115]，均为正；双换的最终[.0088,.3810]为正、平均[-.0345,.4124]跨0。Person替换因此是当前更值得优先真实验证的控制，不能仅按最终33.0608最高就选择双换。此结论仍限于已探索的seed1保存预测。

## 3. 第一优先级：保留强Full，复用完整的辅助Task Forward

### 3.1 用MULTI-LANE的数据流描述

对当前任务t，仍使用三路Frozen Forward图像证据和Task Forward；任务身份由既有路径决定，推理时运行所有已见任务路径并按类别归属汇总，不按真实标签选择最佳路径。

```text
Full图像   → Frozen Forward → A的Selectors/Adapter/Prompts → A的Full Task Forward ─┐
Person图像 → Frozen Forward → B的Selectors/Adapter/Prompts＋Person Attention      ├→ 原特征融合 → B0头
                                     → B的Person Task Forward ────────────────┤
Face图像   → Frozen Forward → B的Selectors/Adapter/Prompts＋可靠Face Attention     │
                                     → B的Face Task Forward ─────────────────┘
```

上图对应同时换两辅助分路；只换Face或Person则把另一条保留A。分类头仍在原特征融合后，使用同阶段B0头。

R3中的Person和Face继续共享B原来那套任务参数库，A的Full保留A库；并非重新创建三套相互无约束的Selector。R1则Full/Person继续共享A库，Face使用完整B来源。参数分配由已验证的功能来源决定，初始化时应精确重放各来源分路。

**重要依赖：B的Person/Face Attention原先读取B产生的Full摘要。** 必须保留产生该摘要的必要B参数和计算，不能擅自用A的Full摘要替换，然后声称仍保留B的Face函数。Full最终分类特征来自A，与辅助Attention的Full摘要来源可以不同。

不同参数版本可以共享冻结ViT权重，并有机会缓存同一视图Frozen Forward的中间tokens；但额外Summarize/Task Forward、参数存储和缓存都需要实测。初版可用两个完整模型前向验证功能，再优化共享缓存。不能提前宣称只有原模型的成本。

已保存checkpoint使本次验证无需新训练；若把它写成正式方法，训练来源包括B0头、Person-only和Person+Face三次各30epoch/任务，共90epoch/任务，再加后续适配预算。不能拿这种来源组合与只训练一次30epoch的基线宣称等预算。推理只需保留B0头及所需任务参数，不需要保留第三个B0视觉骨干。

### 3.2 为什么区别于失败的独立Selector实验

- 失败版让三套Selector从相同初值分别重学，同时继续改变共享Adapter/Prompt。
- 新方案保留已学习好的完整分路：Adapter、Selectors、Prompts、Attention、必要Full摘要来源和同一B0读出一起保留。
- 因而分路初始函数应与来源checkpoint一致，既不重新随机训练Selector，也不单独把某个参数块搬进另一个已共适应系统。

这是先复用已获得的功能，再检验功能组合；它还不是关于某个新Attention模块创新性的证据。

## 4. 第二优先级：若需要重新训练，保护输出功能而不只固定分类头

固定分类头不保证输入该头的特征仍然有效；冻结整个模型又可能限制新分支共同适配。因此若目标是收敛到一个共享任务参数库，可研究**分视图教师约束**。

使用两个冻结的同阶段教师：A提供Full/Person目标，B提供可靠Face目标。学生从B已经学好的共训路径初始化，保留原融合BCE/辅助监督和Adapter-ASL参数组分工；分类头是否可小步更新单列控制，不再把固定头本身当作保护机制。

概念目标是：

`L = L原监督 + βF D(zFull学生,zFull_A) + βP D(zPerson学生,zPerson_A) + βface·r D(zFace学生,zFace_B)`。

多标签应使用逐类Bernoulli分布约束或合理的logit距离，不能直接套互斥类别softmax；当前任务只监督合法类别，旧任务路径仍冻结。教师与学生读取相同增强样本。优先约束最终Task CLS读出，不直接要求不同教师所有Selector槽位逐元素相同。

借鉴的是[Learning without Forgetting](https://arxiv.org/html/1606.09282v3)保持已有输出功能的思想。这里保护的是同一任务中的视图能力，并由另一个教师保留已学好的Face能力，不是把整体更弱的Face软标签灌入Full。该差异很重要：2026-09-13的Person/Face→Full OOF概率蒸馏已经失败，不能把那一方案换名后重复。

最小训练控制：相同初始化/更新预算下，无保护、仅Full/Person保护、再加Face教师。先固定一套权重验证功能保持与新贡献，再研究自适应权重。已有教师训练、学生更新和缓存成本必须单列，不与单次30epoch基线声称等预算。

这属于软约束，不能数学保证Test预测不变；若教师目标互相不兼容，一个共享参数库仍可能无法兼顾。它的把握低于先验证完整来源路径的直接组合。

## 5. 第三优先级：针对共同训练速率与互补价值设计模块

如果固定组合得到真实前向及更多seed支持，再考虑一个轻量受限门控，在原分路与新分路之间逐任务/类别或按图片选择插值程度。初版优先少参数、固定权重控制，Face无效时强制原逻辑，所有已学任务门控冻结。

门控的目标应是“这条新分路是否纠正当前融合错误”，而非Face是否清晰、Face单路置信度是否大。原B分路已较好分类，不能把大置信度自动当成互补证据。TRAIN内门控若使用OOF/holdout，源模型也必须匹配对应划分；对已用全部TRAIN训练的教师事后划holdout，不能称其为教师未见数据。当前没有启动门控训练。

只在最终每类统一调阈值或施加正温度的单调变换，不能提高该类AP。若研究校准，应让它作用于分路混合之前或改变不同人群/内容的相对贡献，才可能改变最终排序；仍须以固定权重控制判断价值。

若希望仍完全端到端共训，可参考[Gradient-Blending](https://arxiv.org/html/1905.12681v3)按不同视图的泛化/过拟合行为调节监督贡献，而不是一律等权辅助损失。但这只是有针对性的备选；现有结果尚未证明某种梯度冲突或Full主导是唯一根因，不能直接套PCGrad/OGM并承诺收益。

当前视图还共享参数，Adapter用ASL、其他参数用BCE，两类梯度需分别处理。降低Face辅助损失权重并不消除Face的融合主损失路径。没有针对这些实际路径的诊断和控制，就不能把“梯度均衡”当作已经实施的隔离。

## 6. 推荐的研究顺序与成功标准

1. **已有预测的整路组合（本次已完成）**：确认强Face不是只能提高单路分数。结果有正信号，Person替换信号更强。
2. **完整模型无训练验证（建议下一步）**：优先R1/R2/R3，保留R0和R4控制。检查两个Test mAP均高于A，逐路函数来源正确，并报告Val/Test全部8阶段和成本。
3. **再选择是否压缩或重新训练**：如需要单共享库，用双教师功能约束；如接受更多小型任务参数，保留完整辅助Task Forward，先不要破坏已有增益。
4. **门控或新Attention最后做**：只有固定组合已显出可利用互补，才增加学习“何时使用”的自由度。对Face/目标人物条件的结构研究仍需同图人物交换等机制检验，而不是只按总mAP推断。

重点参照是32.8864/39.8687，而非只超过32.6800。最终mAP和阶段平均同时正向，才能满足用户当前目标。单seed的小幅探索收益、离线混合或部分阶段改善均不升级为稳定结论。Test继续按用户授权用于探索，完整报告所有固定候选及其选择过程。
