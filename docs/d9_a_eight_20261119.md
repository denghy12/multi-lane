# 从等权学习任务平均比例 A 的八任务验证

## 学什么

三路 MULTI-LANE 分别读取整图、目标人物和人脸。Person 和 Face 在第9个 Frozen Forward block 后进行跨视图交互，各路由自己的 Task Forward 和分类头给出当前情绪的分数。A 接收每路的分类分数及 Face 是否可用。对于一个给定任务和 Face 可用状态，所有人物共用一套比例。

每个任务有两行初始为零的分数。用 softmax 转为比例之前屏蔽不可用的 Face。可靠人脸的三路从等权 1/3 开始，其他人的 Full、Person 从等权 1/2 开始。用同一人物的三个分类分数按比例加权，以融合后的分数和 TRAIN 情绪标签计算 BCE，只更新形成两行比例的分数。上一轮用于收缩人物调整的 λ 和第10层人物信息均未进入 A 的计算。

## 数据和验证

沿用 seed1 的 90/10 实验。EMOTIC 官方 TRAIN 依据原图划分，同图所有人物及其裁剪在同一侧。Frozen9 模型的可训练分支使用约90%的原图，各任务训练30轮，batch64，主学习率0.0125，Adapter 与交互模块0.0004。复用同一条训练轨迹的八个分支 checkpoint。每个任务用它自己的引入阶段 checkpoint 预测约10%侧的当前任务人物；这些人至少有一个新情绪为正。每个已知情绪的负标注也进入 BCE。各任务的融合训练人数依序为558、439、80、995、423、251、62、126；同图可能在不同任务出现，八行人数不能相加作为唯一人物数。

A 单独用该任务留出 TRAIN 的三路分数做全批 BCE，Adam 学习率0.01，300步。该任务的比例随后封存。阶段 t 对截至当时引入的所有类别逐头融合、拼接，按历史已见人群和类别计算 mAP。Validation 与 Test 均不更新参数，依次评价。主比较为同一份分支预测上的 A 与历史固定权重；受保护全 TRAIN 分支的固定融合是另一条训练轨迹的绝对参照。最终 mAP 来自第八阶段的26类，阶段平均是八个阶段 mAP 的算术平均。

入口为 `bash scripts/emotic/run_d9_a_eight.sh` 的 smoke、extract、evaluate 三个阶段。GPU0 只提取缺失的TRAIN分支预测；A 在 CPU 拟合和评价。输入使用历史 `sample_holdout` 的 compact_checkpoints、cohorts、evaluation 及上一轮 task0/3/6 缓存，输出、日志分别在 `output/d9_a_eight/seed1_20261119` 和 `logs/d9_a_eight/seed1_20261119`。

A 相对同分支固定读出，Validation 八阶段全升，Test 八阶段全降。Test 最终和阶段平均差为 −0.0755／−0.2413。90%分支即使用历史固定比例，距全TRAIN参照的 Test 两项也已低 0.7446／0.3164。合起来，A 距全TRAIN固定参照还差 0.8201／0.5576 点。两条分支训练轨迹的差异包含数据覆盖和更新次数。

按 Face 可用性复算，Test 不可靠组的 A 相对固定为 +0.2583／+0.1786，可靠组为 −0.0921／−0.2675。两个子群 mAP 各自在组内排序，全体还包含跨组人物之间的排序，不能对两个差值作人数加权来反推全体 mAP。最终 Test 按类别所属任务拆分，task3、6 平均各提升0.7317、0.8008点，task0、4、5的平均分别下降0.5637、0.6526、0.9635点。

同一任务、同一Face状态的所有人物得到完全相同的权重。该结果检验从 TRAIN 学习任务平均配比的效果。分类头、Frozen9 消息和已有分支输出没有改变。本轮为单个seed的缓存读出，不能据此推定人物层面的动态选择是否有效。若继续定位，先在同一份预测中分别只替换可靠组、只替换不可靠组的比例，复算全人群 mAP。

代码运行版本 8c8cc83。首次严格重放发现，CPU单线程计算 sigmoid 时，Test 最后阶段一个子群的固定融合 mAP 和来源相差约0.000009点。恢复历史八阶段评估的两线程，并为旧三任务探针保留其原单线程设置后，固定、等权和旧探针均通过重放。原比例及Validation封存记录一致。GPU真实TRAIN预检、10项回归通过，33份结果、缓存与日志已同步本地并逐文件核验。
