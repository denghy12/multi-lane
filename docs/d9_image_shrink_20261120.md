# 一张原图一套比例，学习整图调整的幅度

问题是之前从原图预测出的权重能否在较小的调整幅度下改善自然图排名。训练记录、模型及输入承接 d9_image_gate_20261120。等步数90%视觉分支接收第9层跨视图信息，分支保持冻结。对于原图 I 和阶段 t，用上一轮从 TRAIN 学出的图级可用性常量 A 和从图像算出的权重 w(I)，计算 (1−λ)A + λw(I)。A 与 w 使用同一个完整目标框名册决定的 Face 掩码。当前模型的全部已见类别、同图全部人物共用同一比例。“只看 Full”与“Full 加关联”分别有一个公共 λ，阶段结束时更新它，再应用到所有已见任务头。

在官方 TRAIN 的原10%留出里，以固定的哈希将原图分三折，不同阶段同图固定归折。三条折内轨迹各自从等权开始，按任务顺序训练常量/Full/Full加关联，Adam 0.01、每任务300步，训练误差先按图平均；各折标准化仅用其 task0 拟合部分。记录对未参与该折门控学习的原图的预测，避免让拟合过本图的门控来评价自身调整的价值。视觉分支此前也未使用这些原图。按当前新类和当前合法 TRAIN 人物算折外 AP，每类只计兼有正负例的折，并记录缺失支持。对 0、0.05、…、1 的每个幅度记录结果。每阶段按截至当时各阶段等权平均的折外真实 mAP 选一档，完全并列取最小；允许继承历史曲线，不访问未来。三折用于选幅度。正式 Val/Test 仍用上一轮在全部合法留出 TRAIN 上学出的两个端点；评价集的标签及权重均值都不参与 λ 的选择。

指标为八阶段自然 Val/Test 最终和阶段平均 mAP。各候选同时与同规则学习常量、同规则固定、未收缩、同图级 Face 掩码内交换100次及去除图间差别的组均值比较。均值与错图只作归因。优先检验整图加关系组是否在 Val 两项同时严格超过学习常量及交换；同时报告与图级固定的差值，再用锁定方案报告 Test。若 λ 很小，报告其折外成绩与零调整的差距。单种子、21档及这一条插值线限定结论范围。
