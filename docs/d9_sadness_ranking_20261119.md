# 全 TRAIN 与 90/10 的 task6 Sadness 配对排名复盘

主实验复用 seed1、全 TRAIN 的受保护 Frozen9 三路。task6 当前任务用627人、562张原图，441人有可靠Face，含260名 Sadness 正例。分支按历史每任务30轮、batch64学习，Full 与 Person 用过这些人物，Face 遵循原筛样。重新提取该模型第10个 Task Forward block 输出的三路 Task CLS，以既有固定投影与 TRAIN 标准化得到12维。融合用全部627人，从有效视图等权开始，全批 Adam、LR 0.01、300步。A 为组常量，B 为个人 BCE 读出，C 同结构增加系数1的平均真实标签概率监督。分支不更新。全 TRAIN 的同源历史固定比例和同源 A 分别作为对照。仅复盘 task6 引入阶段。另读取90/10已有封存参数完成人群对照，该组拟合用62人。

两侧均在当期全部已见人物上计算单类 Sadness AP。用原 float32 sigmoid 和官方排序复现基准后，以 A 或固定比例为起点重算仅正例换 C、仅负例换 C、所有人换 C 的排名。保留可靠 Face 标记；将人物分数变化按相对 Full 的 Person、Face 两项拆分，并统计翻转的正负对。平均两种替换顺序用于描述 AP 的变化，翻转对数量本身不等于 AP 的贡献。Validation 封存后复核 Test。使用标签的混合方式仅作诊断。

入口为 bash scripts/emotic/run_d9_sadness.sh，产物在 output/d9_sadness/seed1_20261119、日志在 logs/d9_sadness/seed1_20261119。原 checkpoint、历史权重和预测均只读。

## 结果

全 TRAIN 组的三路输出与原模型在两侧逐人重放。五项回归和真实批次预检通过。Validation 为 2,397 人（113 名 Sadness 正例），Test 为 5,367 人（241 名正例）。这次只重新拟合全 TRAIN 的当前头融合层，90/10 组直接复用封存读出。各分支参数未更新。执行版本 2b646e6，五个阶段退出码为 0；41 份缓存、结果与日志已同步本地并逐文件核验。

以全 TRAIN 的历史固定读出为起点，正例调整单独提高两边 AP，负例调整使两边 AP 大幅下降。平均两种替换顺序，正例部分对应 +6.9355/+4.0270，负例部分对应 −20.8360/−24.9114（Val/Test）。全 TRAIN 的 A 已经将可靠组的 Full/Person/Face 配成约 3%/33%/64%，不可靠组为 6%/94%/0%。C 对 A 有改善，但使用 A 作唯一起点会漏掉相对同源强基线的大幅退化。C 的逐人三路份额换为封存的自身组平均后，Sadness AP 为 Val 27.2489、Test 34.0605，两个 split 对人物变化的判断不一致。

固定换 C 后，Val 前 50 名的正例由29人降为20人，Test 由44人降为26人。核对逐人档案（基准名次大于50、C名次不超过50且该类标签为0），新进入前50的负例在 Val 为20人、Test 为22人。其 Sadness 分数全部升高。Test 新进入的22人中19人有可靠 Face。在相对 Full 的分差分解中，18人的 Face 项比 Person 项更大。Val 相应计数为20人中13人有可靠 Face、13人 Face 项更大。统计所有新翻转的正负对时，Person 项在 Test 88,152 个新增错排对中的52,365对更大，Face 项在35,787对更大。最前面少量负例与全体错排对反映不同范围，不能将全部 AP 损失归于单一路。

完整八任务的历史固定读出为全 TRAIN Test 33.2019/40.2847、90/10 Test 32.4573/39.9684。本轮数字分别是 task6 当期三类 mAP 和单类 Sadness AP。两个全 TRAIN 对照共享同一批627名分支/融合训练人物，其中所有人至少命中一个当前类。上述同分支替换定位了排序下降的人群，训练曝光与负例覆盖各自贡献尚未分离。
