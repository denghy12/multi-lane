# Face 更新预算与同配方学习融合的缓存验证

EMOTIC，seed1，全部八任务，90% 分支原图与 10% 融合专用 TRAIN 原图均沿用历史划分。候选在三个清晰度条件中分别取等步数模型 Full、Person 和原预算模型 Face 的对应 logits。用两来源同一批人、相同类别和 Face 标记重估配对 A。每个任务仅使用当时的留出 TRAIN，将可用视图等权初始化，用 Adam 0.01、300 步、每人物等权的多版本 BCE 拟合分组比例。当前任务的 A 封存用于该任务类别。固定比例仍为可靠 64/16/20、不可用 80/20/0。最终输出为加权 logits 的 sigmoid。

按自然 Validation 八阶段和原 AP 实现比较全体、可靠、不可靠人群；先完成 Validation 封存，再同批评估 Test。是否推进单轨迹训练在 Validation 阶段确定：候选学习比例两项均达到候选固定比例，且至少一项达到当前正式等步数 A。严格使用未舍入数值。另列与历史全 TRAIN 固定的距离。Test 不参与拟合或推进决策。该混合预算缓存由两条历史轨迹生成，仅用于验证训练假设。

运行入口为 `bash scripts/emotic/run_d9_face_budget_probe.sh`。只用 CPU，复用现有预测和原配对 A 实现。结果存放在 `output/d9_face_budget_probe/seed1_20261120`，运行日志在 `logs/d9_face_budget_probe/seed1_20261120`。

## 已完成结果

两个来源的留出 TRAIN 均重放各自的 A，逐任务核对人物、标签、Face 标记。两个 split 的同源固定读出及等步数 A 均在各阶段、各人群逐类重放。正式运行的三项测试通过，8 份结果及日志已同步并逐文件核对 SHA-256。

**Validation 的决定为保留当前正式 A。** 候选相对自身固定为 +0.2064／+0.0706，相对当前正式 A 为 −0.0373／−0.0675，八阶段仅 task0 高于当前正式 A。按预定判据，未启动单轨迹分支重训。

**Test 有两个不同的对照。** 候选相对当前正式 A 的八阶段全部提高，最终／平均增加 0.0868／0.1090 点。相对候选自身固定，最终提高 0.0887、平均降低 0.0899，5/8 阶段下降，前两阶段分别为 −0.4223、−0.2819。相对全 TRAIN 固定的两个目标，最终仍低 0.0550 点，阶段平均高 0.0051 点。

无可靠 Face 时，原预算 Face 的替换被 mask 掉，八个任务该组学习比例与当前正式 A 最大绝对差为 0，两 split 的这组阶段指标重放。可靠 Face 组内候选相对当前正式 A 的 Test 最终／阶段平均由 33.5112／40.6053 变为 33.6706／40.7606。相对候选自身固定，这组的 Test 阶段平均由 40.8474 降至 40.7606。全体 mAP 还包含两组之间的相对排序。预算与重新拟合的可靠组权重同时改变，结果只能说明这个组合的作用。在本次 seed1 缓存上，未出现同时满足既定两道比较的正式候选。
