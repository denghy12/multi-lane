# 一张 EMOTIC 原图产生一套融合比例

## 实验条件

本轮复用 seed1、八任务、90% 分支原图补齐至 13,950 次更新的受保护 Frozen9 三路。按任务顺序重放八份分支 checkpoint 和保存的自然图 logits。每阶段只用该阶段合法的、原 10% 留出 TRAIN 人物的当前新类标签学习公共融合器。相同原图下各有监督人物的 BCE 先平均，再对原图平均。每阶段全批 Adam、学习率 0.01、300 步，从上一阶段的参数继续，Adam 状态每任务重新初始化，task0 全零参数使可用视图等权。标准化统计只用 task0 的留出 TRAIN 原图。当前阶段用同一个门控和同一个图级向量给所有旧类和新类分配权重。跨阶段门控可以变化，八阶段评价会反映这种变化对旧类的影响。

每张图用预定标注目标清单和人脸清单统一判断 Face 是否可用。只要有一个目标无可靠脸，全图都按 Full／Person 两路分配。图中全部目标都有可靠 Face 时，全图按三路分配。图清单独立于本次评价中哪些人物有当前情绪标签。即便关闭 Face 的末端权重，Person 的原 Frozen9 路径仍可保有此前传入的辅助信息。

| 读出 | 输入 |
|---|---|
| 历史固定 | 原来的逐人 Face 可用性和固定比例 |
| 原图级固定 | 用图级可用性，可靠图 64／16／20，其余 80／20／0 |
| 训练得到的常量 | 两种图级可用性各自学习一套比例 |
| 整图 | 公共偏置加 Full 原生冻结 ViT 第9块的空间 patch 均值，固定低维投影 |
| 整图加关联 | 在整图输入上加本图全部目标的 Person、可靠 Face 与 Full 的第9层原生 Attention 关联汇总 |

整图和关联组计算一次可用视图的 softmax，随后广播给该图所有目标及已见类别。Full 特征与类别无关；关联取当前已学阶段的交互模块，按图聚合后仅产生一次公共权重。关系特征和三路 logits 均停止分支梯度。本轮复用历史 checkpoint 验证新读出，模型来源与后续正式整网从头训练应分别报告。

## 评价

固定所有方法后先评自然 Validation，封存结果及 TRAIN 权重，再评完整自然 Test，历史指标均以 mAP 点报告。举例诊断以整张原图为置换单位，在相同图级可用性内交换或使用组均值，同时报告单人/多人适用性和混合人脸图片的末端变化。先对比新旧固定以估计统一缺脸规则的代价，再比同规则常量、Full、Full 加关联。本人图权重要同时超过组均值、跨图交换以及同规则常量，才支持按图选择带来增益。关联的额外价值由它和 Full 的同底座比较判断。预先以 Validation 最终和阶段平均的共同方向评价，Test 仅作复验。固定比例绝对参照包括等步数 90% 原逐人固定 43.7028／51.2535、32.7557／39.9983 及全 TRAIN 固定 43.6272／51.1094、33.2019／40.2847。

入口 `bash scripts/emotic/run_d9_image_gate.sh 0`。模型源目录为 `../multi-lane-main-d9-holdout-equal-updates/output/d9_equal_updates/seed1_20261119/formal`；EMOTIC、ViT-B/16 和 Face manifest 跟随原实验路径。只读图像特征在 GPU0 小批量提取，分支不重训。先真实 task0 小跑，再八任务。结果在 `output/d9_image_gate/seed1_20261120/`，日志在 `logs/d9_image_gate/seed1_20261120/run.log`。

## 完整人物框核验

从原始人物框核验，TRAIN/Val/Test 分别有 16,001／2,397／5,369 个目标框。Test 有一人没有情绪标签及 Face 记录，仍计入原图目标名单，其 Face 视为不可用。最终阶段 Test 的 3,682 张图中有 2,042 张全有可靠 Face、463 张混合、1,177 张完全没有可靠 Face。图级规则使 628 名原本可靠的评分目标关闭末端 Face；Val 对应为 265 人。图级 Face 可用性只由目标框和 Face manifest 决定。

## 结果归因

原图级固定比例相对原逐人缺脸固定的 Test 最终／平均只改变 +0.0015／+0.0042，Val 改变 −0.1774／−0.1955。图级常量相对图级固定提高 Test 最终 0.2146，阶段平均低 0.2218。仅依赖 Full 或进一步加入关系的两种图级读出，在两个 split 的八个阶段全部低于相同缺脸规则的学习常量。因此，后续的明显下降主要发生在读出随图变化之后。

全图加关系组的 Test 最终／阶段平均为 28.7946／36.9651，同组整图权重交换为 28.5374／37.0496。用评价图无标签权重的组平均作归因，结果升至 32.5187／39.4349，Val 也回升 2.9044／2.2553。组平均使用了各自评价集的无标签图像统计，只作解释。末阶段 Test，2,042 张全部目标有可靠 Face 的图上三路平均权重约 62.1%／16.0%／22.0%，74.0% 的图片给其中一路超过 90%。完全关闭 Face 的 1,640 张图中，该比例为 77.4%。已有 Full 与跨视图输入能让权重明显随图变化；本图与错图对照、组均值与常量表明这些变化尚未转化为稳定的分类排序收益。

最终 Test 的 2,444 名单目标图人物中，图级固定为 33.3517、全图加关联为 29.3691；多目标图中对应为 31.9113、28.3024。单目标图也下降，无法把结果解释为同图多人共用比例这一项限制。融合参数跨任务继承、当前阶段的关系表示随任务变化、仅使用留出 TRAIN 当前新类的人物，以及有限的图像投影，都可能影响权重的稳定性。本轮没有单独分解这几种原因。目标若继续，可在同分支、同图可用性下检验朝 TRAIN 学习常量收缩的逐图调整，用 TRAIN 内原图检验选择调节幅度。

## 核验与产物

5 项回归测试及真实 task0 的 TRAIN／Val／Test 小跑通过，正式八阶段于 2026-11-20 18:50（上海）完成。独立复算的 80 项正式全人群 mAP 与报告一致。额外从最终 Val/Test 各取 8 张完整原图，重做图级特征与全部26类的完整模型前向，分别覆盖 18 和 17 名评分人物。小批量完整前向与历史缓存融合的概率最大绝对差为 0.01468／0.01381，平均差为 0.00057／0.00059。正式整套 mAP 使用真实图级特征、历史已核对的分支 logits 和本次 TRAIN 学习的门控；独立小批量前向用于核验推理流程。训练、评价、权重、报告和日志已同步本地并校验 SHA-256。详细逐阶段指标在 `output/d9_image_gate/seed1_20261120/formal/readout/`，完整表格在同级 `results.md`。

沿用历史同一 64 人原生评价批次再复核，Val 覆盖 64 人、Test 覆盖 128 人。所有人的 26 类三路 logits 均与历史档案逐值一致，抽样原图使用相同已存图级权重后的融合概率也逐值一致。结果见 `formal/native_batch_check.json`。
