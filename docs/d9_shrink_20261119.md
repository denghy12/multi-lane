# TRAIN 内按原图选择人物偏移幅度

seed1，官方 EMOTIC，使用前一轮 90/10 分支的 task0、3、6 checkpoint 已缓存的特征与分支 logits。CPU 单线程。三个任务用于融合的 TRAIN 留出人物分别为 558、995、62。验证与测试使用各历史阶段的官方已见人物，仅计算当前头新类别的 AP，再对三个任务的 mAP 等权平均。

在这批 TRAIN 原图内部建立三折，同图所有人物及不同任务上的出现使用同一折。在其余两折用零初始化、全批 BCE、Adam 学习率 0.01 分别训练 A、D，各300步。D 使用本折TRAIN计算的尺度，保留上一轮12维输入和有符号消息接口。每折只为留出人物产生权重。拼回全体折外预测后搜索一个三任务共用的混合比例，候选从0到1，间隔0.01。计算的是权重的凸组合，进入同一组分类头 logits 的加权和，再按历史规则过sigmoid计算AP。以三个任务折外mAP等权平均最高者锁定，精确并列取较小比例。此分数承担选择超参数的职责。折外基准和最终用于推理的 A/D 参数因训练人数不同而有差别。

最后复用上一轮完整留出TRAIN拟合的 A 和 D。Validation、Test 使用同一锁定比例，包含固定融合、A、D、本人混合比例、实际平均比例和同任务同可靠性内100次错配对照。只换消息时保留本人的任务内容及原三路分类分数。Validation 要求本人混合同时超过 A 和错配消息，各项三任务宏平均为正且至少两个任务为正。Test 同口径报告。跨任务共用的比例读取了三个任务的TRAIN信息，这属于回顾性诊断，不能视为在 task0 部署时已可获得的超参数。固定基准的完整八阶段 mAP 需另行验证。

入口为 bash scripts/emotic/run_d9_shrink.sh。输出位于 output/d9_shrink/seed1_20261119，日志位于 logs/d9_shrink/seed1_20261119。
