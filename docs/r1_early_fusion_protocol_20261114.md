# 提前学习融合与训练原图比例

EMOTIC历史划分、seed1、8任务，GPU0、1。数据在 ../multi-lane-main/datasets/EMOTIC，使用 ../CODE_DDP/pretrained/clip/ViT-B-16.pt 和既有Face可靠性清单。诊断来源为前一批 c957d66 的 output/r1_fusion_population_train/seed1_20261113。新工作树在其同级，产物 output/r1_early_fusion/seed1_20261114，日志 logs/r1_early_fusion/seed1_20261114。

第1步用 export_r1_early_fusion，GPU0承担task0/3/4/7，GPU1承担1/2/5/6。每卡解码一份原图供三视图使用。保持batch64、AMP、确定性顺序与正/负原分批。取各任务完整epoch15，按原epoch30实际输出抽检同一读取路径。随后 evaluate_r1_early_fusion 按原图三折做TRAIN交叉预测，对比epoch15与30；在全部TRAIN留出拟合锁定后，同批计算原轨迹第35轮八阶段Val/Test。两参数、等权初值、Adam lr=.02、BCE100步。每个任务只用其当期类别，扩大人群可访问具有已见类且当期全阴性的历史TRAIN留出人物，历史成本沿用源协议。

预先采用保守的分流标准：epoch15学出的权重在epoch30同人物折外预测上的真实AP（先对任务内按类平均，再对8任务平均），以及应用到同来源第35轮分支的Val最终、阶段平均，三者对固定比例均至少持平；只容许1e−4个mAP点计算误差。Test仅用于随批报告，不参与分流。已有第2至第8任务的e15状态继承上一任务原35轮训练，e15迁移仅是候选成熟度诊断。

若通过，正式从预训练模型按单轨迹训练：每个任务总30轮，前15轮当前任务约80%原图学习分支，随后本模型在同一扩大TRAIN留出学习融合100步并封存，后15轮全部当前任务TRAIN参与。连续30轮cosine、保留Adam状态。B64、主LR.0125、Adapter与Frozen9交互LR.0004、WD0，原BCE及Adapter-ASL、历史增强与Face训练筛样。Full/Person/Face放在GPU0/1/0，各进程只看一块卡，保留每分支随机流；同模型固定/学习读出完整Val/Test。若未通过，仅在已有第30轮同一扩大TRAIN缓存上对比BCE与每类正负对平均softplus排序损失，共用原图三折、参数、初值、预算，双split评估。

划分论证：同一个原图哈希与固定盐，70/30、80/20、90/10三种嵌套阈值，先核对当前任务训练正例、留出正例、类别与Face可靠性支持。对现有80%训练的分支再使用10%和20%融合留出，按同一折外人物比较样本量作用。30%留出包含已参加80%分支训练的图片，仅做覆盖审计。这里不会把不同分支训练比例的精度优劣当作已有证据。
