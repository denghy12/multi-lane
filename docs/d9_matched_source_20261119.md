# 同一90%模型上，比较已见和留出 TRAIN 人物学出的平均融合比例

## 预定协议

保留第9层 Cross-view Attention、三条 Task Forward 及原分类头。EMOTIC、seed1、task0/3/6 的原 sample_holdout 八任务轨迹。三路按原图约90% TRAIN、30轮、batch64、Adam/cosine、主学习率0.0125，Adapter/交互0.0004训练；冻结各任务引入时的 checkpoint。仅访问已知的当前新类 TRAIN 标注，沿用至少一个当前类别为正的合法人物，Face 自身训练仍受原筛样约束。分支训练的90%和永久留出10%按历史全局原图角色重放。

保留所有合法留出人物，从已见侧无放回选取等量人物。不用图像分数、质量变化输出或任何评价数据匹配。以可靠 Face 分层，尽可能同时匹配原 Face 训练筛选状态和本任务完整多标签组合。不足时记录回退、标签与人群人数差，输出两侧原图数、逐类正负数与样本身份。该比较是观察性匹配，剩余的场景、质量等差异另行披露。

GPU0 对两侧都用相同的确定性输入获取自然图像、仅降低 Person 分辨率、仅降低可靠 Face 分辨率的前向。采用历史 224→112→224 操作，同时改变同视图自身及发送证据，整图和不可用 Face 的回退逐值核对。留出自然版本对照原模型的 TRAIN 缓存。每人总权重相同，取各自可用版本的 BCE 均值。分别学习两个当前任务组平均 A（以 Face 是否可用分组），等权起步、全批 Adam、学习率0.01、300步。配置相同，唯一区别为监督人物来源。Validation/Test 只评价原始自然图片，覆盖对应阶段所有已见类评价人物，只计算当前头的11个新类，每任务内平均后再对三任务等权平均。

先按 Validation 判断。若留出 A 相比已见 A 三任务均值为正且至少两项任务为正，触发后续逐人比较；另独立报告其距同组三路历史固定融合多远。若触发，用留出 TRAIN、相同清晰度配对重新训练 B/C，两者冻结同一留出 A 和相同输入、更新预算及尺度。从零个体偏移开始，B 学融合 BCE，C 另加原设定的同人辅助收益差监督（系数1）。以按可靠性组减去偏移均值的有界修正保证模型权重非负且总和为1。就实际平均配比提供两项约定：一是用每个评价组所有无标签人物的偏移均值作归因，使 B/C 各自在同一评价组的三路平均严格重放 A；二是固定 TRAIN 自然组的均值作单人推理，此时在评价组允许自然漂移。前者不能作为独立逐人部署方式。B/C 同时报告同组换人和 C 组均值。推进标准为在 Validation 上 C 同时胜过 B、A 和本人权重错配（每项平均为正且至少两任务为正），并达到同底座固定的三任务平均；独立推理也须达到同样条件。模型、选择及参数在 Test 前封存。此批不以90%底座的三任务分数代替受保护全 TRAIN 八阶段目标。

入口 bash scripts/emotic/run_d9_matched_source.sh（smoke、extract、fit-val、test）。来源为 sample_holdout 的 compact_checkpoints、cohorts、train_image_roles.json 及 task10_probe 的 features。输出 output/d9_matched_source/seed1_20261119，日志 logs/d9_matched_source/seed1_20261119。
